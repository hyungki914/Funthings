## 다시 렌더링하기

SVG가 원본(소스)이며, 아래로 PNG와 보드를 재생성합니다.

```bash
pip install cairosvg pillow
# 한글 폰트 필요: Noto Sans CJK KR  (render.py의 FONT 경로 참고)
python3 render.py     # 5개 화면 PNG + png/board.png 생성
```

개별 SVG는 어떤 브라우저/벡터 툴에서도 바로 열람·편집 가능합니다.
색·문구·레이아웃을 SVG에서 수정한 뒤 `render.py`로 다시 뽑으면 됩니다.
