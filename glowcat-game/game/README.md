# 🎮 플레이 가능한 버티컬 슬라이스 — 챕터1 「지로의 방」

웹 게임 프로토타입. **무설치·오프라인** — `index.html`을 브라우저로 더블클릭하면 바로 플레이.
빌드 플랜: [../10_build_plan.md](../10_build_plan.md) · 아트: [../09_art_direction_pixel.md](../09_art_direction_pixel.md)

## 조작
| | |
|---|---|
| 이동 | `WASD` / `←↑↓→` |
| 조사(줍기) | `E` (조각 근처에서 `조사 [E]` 표시 시) |
| 직감 힌트 | `H` (빛 자원 1 소모 → 가장 가까운 코어 방향) |
| 은신 | `Shift` (Murk 시야 60%로 축소) |
| 음소거 | `M` · 회상 계속 | `Space` |

## 목표
방을 탐험해 **코어 기억 3개**를 찾아라(글로우 OFF·3단 발견 → 접근 시 `조사 [E]`).
**Murk**(그림자)에 닿으면 메모리 미터가 깎이고, **0이 되면 후퇴**(안전지대로 귀환 + 최근 코어 1개 임시 봉인 — 영구 손실 X).
침대 앞은 **안전지대**(회복). 코어 3개를 모으면 상단 **문이 빛나고**, 문에 닿으면 **챕터 클리어**.

## 구조 (모듈 분리 — 멀티에이전트 개발)
| 파일 | 역할 | 담당 |
|---|---|---|
| `index.html` | 스캐폴딩(스크립트 로드 순서) | 리드 |
| `assets.js` | base64 픽셀아트(배경+스프라이트) — `../art/pixelart.py` 생성 | 리드 |
| `core.js` | 순수 규칙(2게이지·후퇴·시야·발견·정체성) | 게임플레이 |
| `data.js` | 챕터1 콘텐츠(맵·충돌·조각·Murk·서사) | 콘텐츠 |
| `audio.js` | WebAudio 합성(앰비언트·차임·드론·심장박동) | 오디오 |
| `main.js` | 렌더·입력·루프·HUD(core/data/assets 통합) | 리드 |

## 검증 (브라우저 없이)
```bash
node --test core.test.mjs   # 규칙 단위테스트 (17/17)
node smoke.mjs              # core+data 통합 시뮬레이션
node headless.mjs           # main.js 루프 무예외 구동(DOM 스텁)
```
에셋 재생성: `python3 ../art/pixelart.py` → `assets.js` 갱신.

> 본편은 추후 Godot 이식 가능(로직을 순수 `core.js`로 분리해 이식성 확보 — [04 테크니컬](../04_technical_design.md)).
