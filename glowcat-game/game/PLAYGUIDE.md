# ▶ 데모 시연 가이드 — 챕터1 「지로의 방」 (현재 빌드 기준)

> ⚠️ **이 안내가 필요하다는 것 자체가 이번 데모의 1순위 개선점입니다.** 현재 빌드는 *게임 안에서* 목표·조작·피드백을 가르치지 않아(온보딩 부재) "뭘 하는지 모르겠다"가 발생합니다. (개선안은 [00_design_review.md] / 리뷰 후속 반영.)

## 한 줄: 무슨 게임?
기억을 잃은 고양이 **지로**가 방을 돌아다니며 흩어진 **기억(물건)**을 찾는 게임.
이번 빌드의 목표 = **코어 기억 3개**를 찾으면 → 위쪽 **문이 빛남** → 그 문에 닿으면 **클리어**.

## 조작
| 키 | 동작 |
|---|---|
| `WASD`/방향키, 마우스 클릭 | 이동 |
| `E` | 조사·줍기 (물건 가까이 가면 **"조사 [E]"** 표시될 때) |
| **`L`** | **발자국 추적** — 가장 가까운 *미발견 코어 기억* 쪽으로 시안 발자국이 깔림(무료·쿨다운). **길 모를 때 이걸 누르세요.** |
| **`Q`** | **기억 비추기** — 빛(자원)을 써서 앞을 비춤 → **숨은 기억**이 드러나고 **그림자(적)를 밀어냄** |
| `Tab` | 기억 일지 — 되찾은 정체성·모은 기억 확인 |
| `Shift` | 은신(적 시야 줄임) · `H` 힌트(빛 소모) · `M` 음소거 · `Space` 회상 넘기기 |

## 화면(HUD) 읽는 법
- **좌상단 "코어 기억 0/3"** = 핵심 목표 진행도. **이게 3/3이 되면 문이 열립니다.** (제대로 하고 있는지 = 이 숫자를 보세요.)
- 그 아래 **빛 게이지** = `Q`(비추기)·`H`(힌트)에 쓰는 자원.
- **우상단 `?` 초상 + "정체성 n/5"** = 지로가 자길 얼마나 되찾았나. 기억을 모을수록 또렷해짐.
- **하단 발바닥 10칸 = 메모리(생명)**. 적(그림자)에 닿거나 *가짜 기억*을 주우면 깎임. **0이 되면 후퇴**(안전한 곳으로 돌아가고 최근 기억 1개가 잠시 봉인 — 영구 손실 아님).

## 첫 1분, 이렇게 하세요
1. 시작하면 지로는 방 가운데 **러그** 위에 있습니다.
2. **`L`을 눌러보세요** → 가장 가까운 기억 쪽으로 **시안 발자국**이 깔립니다. 따라가세요.
3. 물건 가까이 가면 반짝이며 **"조사 [E]"** → `E`로 줍기 → **회상 자막**이 뜹니다(`Space`로 계속). 정체성·메모리가 오릅니다.
4. **코어 기억은 3곳:** 🎮 게임기 앞(*이름표 목걸이*), 🖥️ 책상 앞(*빛바랜 사진*), 🛏️ 침대 위쪽(*일기장*). 3개를 다 주우면 **위쪽 문이 빛나고**, 문에 닿으면 **클리어**.
5. 오른쪽을 떠다니는 **그림자(Murk)** 는 적 — 닿으면 메모리가 깎입니다. 피하거나 **`Q`로 비춰 밀어내세요.**
6. **어두운 구석을 `Q`로 비추면** 숨은 추억(장난감 쥐·창가 발톱자국)이 드러납니다(선택 수집).
7. 방 가운데 아래 **"하루가 손 흔든다"** 기억은 **가짜**입니다 — 주우면 메모리가 깎여요(진짜/가짜 추리 요소).

## "제대로 하고 있나?" 한 줄 답
**좌상단 "코어 기억 x/3"이 올라가면 잘 하고 있는 겁니다.** 3/3 + 문 도달 = 챕터 클리어.
