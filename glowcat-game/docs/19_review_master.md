## 1. 교차 합의 (여러 직군이 동시 지목)

1. **랜덤 배치(RANDOMIZE)의 부작용 — 최우선** *(디자인·서사·QA 3중 지목)*
   - core 회상이 가구를 지칭("소파 위 액자")하는데 무관 위치에 출현 → 서사·검산주석 무효화.
   - 튜토리얼(1·2장) 학습의도(첫 조각≠함정) 파괴, 난이도 편차·도달성 리스크.
2. **'게임으로서의 압력' 부족** *(디자인)* — 실패 비용(death 없음·setback 사실상 미발동), 적 2종 단조(동일 사각 patrol·LoS 미구현), 보스 컷신 수준, coresNeeded 전 스테이지 3 고정.
3. **접근성·옵션 부재** *(UX)* — 음소거(M) 외 전무. 광과민성/텍스트배율/적속도/색약·일시정지(ESC).
4. **반응형/터치 레이아웃** *(UX)* — ✅ 이번 세션 수정(반응형 캔버스 + 버튼 여유).
5. **정보 과부하·잔여 카피** *(UX·서사)* — 첫 16초 텍스트 과다, 1·2장 구 라벨 잔존.

### P1 — 단기(품질/접근성)
- **접근성 옵션 메뉴**(광과민성 off·텍스트배율·적속도·색약 보조·음소거) + **ESC 일시정지**. *(ux)*
- **HUD/온보딩 정리**: 상시 단축키→1회 토스트, 토스트 위치 하향, 목표 중복 제거. *(ux)*
- **적 다양화**: LoS(차단) 구현, patrol 형태 변주, 스테이지별 속도/시야 차등, coresNeeded 후반 상향. *(design)*
- **중반 BGM 변별**: town을 5·6·7 공유 → 변주/구분. **분기 전용 SFX**. *(audio)*
- **랜덤 도달성 자동검증**: __layoutCheck를 '스폰→코어/문 플러드필(적patrol=벽)'로 확장 + headless assert. *(qa)*
- **회상-위치 정합 강화**: 위치 비종속 문구로 echo 리라이트(랜덤 echo 한정). *(narrative)*

### P2 — 여유(확장/최적화)
- base64 분리·illust 지연로딩(타이틀/엔딩 전용 88KB), 성능 측정 훅. *(qa)*
- hidden echo에 매장된 핵심 반전(e_blank_pov) 노출 보장. *(narrative)*
- 스테이지 중간 진행 저장(현재 스테이지 단위만). 구 canon 문서(12_story_10stage 등) 정리. *(narrative/qa)*
- 정체성 슬롯 패시브 효과(GDD 6-2). *(design)*

## 3. 노트 — 의도된 설계(리뷰어 미인지)
- **직감(H)이 무정보**인 건 의도. 사용자 요청으로 "위치 스포일 없이 '무엇을 할지'만" 알려주는 가벼운 넛지로 약화한 것. 제거 대신 **유료 방향 단서로의 부활**은 P1 후보로만 검토. `core.useHint`는 死코드이므로 정리 가능.
