# 상세 문서 ⑯ — 원화(Key-Art) 컨셉 디자인 『잊혀진 발자국 / Lost Pawprint』

> 상위 문서: [15_story_revision.md](./15_story_revision.md) · [14_env_art_review.md](./14_env_art_review.md)
> 렌더 파이프라인: [art/pixelart.py](../art/pixelart.py) (PIL primitives)
> 대상: 인터스테이지 **깨달음(회상 몽타주)** 1장/스테이지 × 10 + **엔딩** 2장 = **총 12장**
> 감정 비트 출처: 15 C) epiphany. 톤: **절제·따뜻함·시린 희망** (어둠/공포/신파 금지).

이 문서는 손으로 그리는 원화가 아니라, **PIL 프로시저럴 합성**으로 빌드할 컨셉 스펙이다.
엔지니어는 이 문서의 hex·좌표비율·레이어 지시를 `build_scene`/`apply_grade`/`apply_skylight`/`add_glow`/`add_vignette`와 동일한 원리의 합성 코드로 조립한다.

---

## 0. 공통 스타일 가이드

### 화면/좌표 규약
- **비율 16:9**, 네이티브 권장 **480×270**(= pixelart.py와 같은 저해상도 → NEAREST 업스케일). 좌표는 모두 **비율(0.0~1.0)** 로 표기. `x=0.0`=좌단, `1.0`=우단 / `y=0.0`=상단, `1.0`=하단.
- **하단 1/3 (y 0.66~1.0) 는 "텍스트 안착존"** — 회상 카피가 얹힌다. 이 구역은 단색에 가깝게(저대비, 어두운 그라데이션 바닥), 실루엣·파티클을 과밀하게 두지 않는다. 포커스 오브젝트는 가능하면 y 0.30~0.62 사이(중상단)에 둔다.

### 3층 레이어링 원칙 (모든 컷 공통)
1. **배경(BG)**: 세로 그라데이션 2~3색. 시간대·감정의 베이스. `apply_grade` 또는 단순 vertical lerp.
2. **중경(MG)**: 광원 + 주요 실루엣(가구/벤치/문/나무/지로). `add_glow`가 물릴 광원 코어가 여기 위치.
3. **전경(FG)**: 비네팅, 낙엽/먼지 파티클, 바닥 그림자, 텍스트 안착 어둠. 항상 약하게.

### 실루엣 원칙
- 모든 오브젝트는 **채색 디테일 없이 단색 실루엣 + 1px 외곽 없음(블러로 가장자리 녹임)**. 형태로 읽히게.
- 거리감 = 명도/블러. **가까울수록 더 어둡고 선명**, 멀수록 BG에 가까운 명도 + `GaussianBlur(2~4)`.
- **하루는 항상 흐릿한 실루엣**(blur 3~6)으로만. 윤곽이 또렷해지는 유일한 컷은 **재회 엔딩**.

### 글로우(bloom) 사용 — add_glow 트리거 주의
`add_glow`는 **밝은 픽셀만** 추출해 블러+스크린한다. 트리거 조건(코드 기준):
- 시안 계열: `b>150 and g>150`
- 그린 계열: `g>170 and b<160 and r<170`
- 흰색: `r,g,b 모두 >210`
→ **글로우를 내고 싶은 광원·눈·이름표는 위 임계를 넘는 hex로 칠한다.** 따뜻한 주황/노랑 햇살(예 `#ffd28a`)은 g가 충분히 높지 않거나 b가 낮아 **블룸이 약하게만 물린다** → 강한 햇살 코어가 필요하면 중심부를 **흰색에 가깝게**(`#fff4dc`, `#f5f8f8`) 또는 **시안/그린 하이라이트**(`#9be84a`, `#9ef6f6`)로 찍어 코어만 발광시키고, 주변은 주황으로 번지게 한다. 글로우는 **컷당 1~2 소스**로 제한(절제).

### 연속성 모티프 (12장 전부에 최소 1개)
- **지로**: 작은 검은 고양이 실루엣 + **빛나는 눈**(`#9be84a` 그린 / `#34e2e2` 청록) — 눈은 항상 add_glow 트리거. 입 `:3`.
- **반복 사물**: 창가의 빛 / 발자국 / 가로등·햇살 / 빈자리 / 마른 잎 / 물그릇(길고양이 배려).
- **컬러 내러티브**: 1→4 따뜻함이 식어 청회로, 5→9 다시 햇살·황혼으로 데워지고, 10에서 무채색, 엔딩에서 **그린(재회)** 또는 **시안(길고양이)** 으로 만개.

### 지로 표준 실루엣
- 앉음: 작은 삼각 둥근 덩어리 + 두 귀(삼각) + 위로 컬한 꼬리. 폭 화면의 약 0.06~0.10.
- 눈: 2px 점 2개(좌상 광원이면 약간 좌측), `#9be84a` 또는 `#34e2e2`, 1px 흰 하이라이트로 코어 발광.
- 포즈 키워드: `앉음 / 올려다봄 / 걸음(옆모습) / 달림(앞으로 늘어진 실루엣)`.

## 1. 깨달음 12장 컷 스펙

> 각 컷: **구도(레이어 배치) · 팔레트 · 광원 · 지로/하루 · 분위기 1줄 · PIL 힌트**.

---

### 컷 1 — 지로의 방 (각성·창가 빛)
- **구도**
  - BG: 방 어둠. 우상(x0.62~0.95, y0.05~0.55)에 **창문 직사각 빛기둥**.
  - MG: 창 → 바닥으로 떨어지는 **빛 웅덩이**(x0.55~0.85, y0.55~0.72, 사다리꼴). 좌측에 침대/책상 낮은 실루엣.
  - FG: 지로 — 빛 웅덩이 가장자리(x0.40, y0.58)에 **앉아 창을 올려다봄**. 비네팅.
- **팔레트**: BG 그라데 `#1a1428`(상)→`#241a30`(중)→`#10131f`(하) · 실루엣 `#16110e` · 광원/창빛 코어 `#fff4dc`, 번짐 `#ffd9a0` · 글로우 트리거 `#fff4dc`(흰)+지로 눈 `#9be84a`
- **광원**: 우상 창. 부드러운 직사 아침빛, 세기 중. 먼지 떠다니는 빛기둥.
- **지로/하루**: 지로 앉아 올려다봄, 눈 그린 발광. 하루 없음(각성 직전, 빈 방).
- **분위기**: *흩어진 조각이 처음으로 한 줄기 빛 아래 모인다.*
- **PIL 힌트**: 남보라 세로 그라데 + 우상 사각 빛기둥(흰 코어 사각 → GaussianBlur 6) + 바닥 사다리꼴 빛 웅덩이(alpha screen) + 좌측 가구 실루엣 + 빛가 지로 실루엣(눈 2px 그린) + add_glow + add_vignette(0.5). 하단 1/3은 빛 웅덩이 밖 어둠.

---

### 컷 2 — 거실 (함께한 일상·빈 소파의 온기)
- **구도**
  - BG: 따뜻한 실내 그라데. 우측 창에서 낮은 측광.
  - MG: 중앙~좌(x0.20~0.62, y0.42~0.70) **소파 실루엣**. 소파 위 한쪽에 **남은 온기(옅은 주황 발광 얼룩)** — 방금까지 누가 있던 자리.
  - FG: 지로 소파 앞 바닥(x0.50, y0.66)에 앉아 빈 소파 쪽을 봄.
- **팔레트**: BG `#2a1d1a`(상)→`#3a2722`(중)→`#1a1210`(하) · 실루엣 `#160f0d` · 광원 `#ffd9a0`, 온기얼룩 코어 `#fff0d8` · 글로우 트리거 `#fff0d8` + 지로 눈 `#34e2e2`
- **광원**: 우측 창 측광(따뜻, 약). 소파 위 온기 얼룩이 보조 발광.
- **지로/하루**: 지로 앉아 소파 응시, 눈 청록. 하루 없음(빈 소파가 부재를 말함).
- **분위기**: *온기는 아직 쿠션에 남아 있는데, 그 자리만 비었다.*
- **PIL 힌트**: 따뜻한 갈주황 세로 그라데 + 우측 측광 screen + 소파 단색 실루엣 + 좌석 위 작은 타원 흰코어 발광(GaussianBlur 4) + 지로 실루엣 + add_glow(온기 얼룩 1소스) + vignette. 하단은 바닥 어둠으로 정리.

### 컷 3 — 2층 계단 (무거운 공기·찬 문빛)
- **구도**
  - BG: 차가운 청회 어둠, 위로 갈수록 약간 밝음(계단 끝 문빛).
  - MG: 화면 중앙 **계단 사선**(좌하 x0.15,y0.95 → 우상 x0.70,y0.30). 계단 끝 상단에 **반쯤 열린 문틈 찬 빛**(x0.62~0.74, y0.22~0.45, 가는 세로 슬릿).
  - FG: 지로 계단 중턱(x0.42, y0.62)에서 **올려다보며 한 칸 오르려는** 자세. 비네팅 진하게(무거운 공기).
- **팔레트**: BG `#10141f`(상)→`#181c2a`(중)→`#0b0e16`(하) · 실루엣 `#0c0e15` · 문빛 슬릿 코어 `#cfe0ff`(차가운 흰) · 글로우 트리거 `#cfe0ff` + 지로 눈 `#9be84a`
- **광원**: 계단 끝 문틈의 차고 가는 빛(세기 약, 좁은 슬릿). 위에서 아래로 약하게 흘러내림.
- **지로/하루**: 지로 올려다봄, 눈 그린(망설임 속 의지). 하루 없음.
- **분위기**: *한 칸마다 공기가 한 겹씩 무거워진다 — 그래도 한 칸 더.*
- **PIL 힌트**: 청회 세로 그라데(상단만 살짝 밝게) + 계단 사선 실루엣(겹친 직사각 계단형) + 상단 가는 세로 슬릿 차가운 흰코어(GaussianBlur 3) + 지로 실루엣 + add_glow + vignette(0.62 강). 하단 1/3 거의 어둠.

### 컷 4 — 하루의 방 (걷힌 이불·멈춘 시계·그날 아침)
- **구도**
  - BG: 청회 새벽빛. 좌상에서 흐릿한 창빛.
  - MG: 좌중(x0.18~0.58, y0.45~0.72) **침대 실루엣 + 한쪽으로 걷힌 이불**(비대칭 덩어리). 우상(x0.70, y0.28) **벽시계 원**(바늘 멈춤). 머리맡 작은 **약병 실루엣**(넘어짐).
  - FG: 지로 침대 빈쪽(x0.40, y0.60)에 **몸을 말고 앉아** 시계 쪽을 봄. 비네팅.
- **팔레트**: BG `#161b2a`(상)→`#202637`(중)→`#0e1119`(하) · 실루엣 `#0d1018` · 창빛 `#aebcd8`(차가운 흰) · 글로우 트리거 약하게(이 컷은 발광 최소) + 지로 눈 `#34e2e2`
- **광원**: 좌상 창의 시린 새벽빛(약). 발광 거의 없음 — 정지·정적.
- **지로/하루**: 지로 몸 말고 앉음, 눈 청록 흐림. 하루 없음(걷힌 이불=부재의 모양).
- **분위기**: *모든 것이 그 아침에서 급히 멈췄다 — 시계마저.*
- **PIL 힌트**: SCENE_FX의 'haru_room'과 동일 무드 차용 — `desat 0.35` + 청보라 multiply 그레이드. 침대+걷힌 이불 비대칭 실루엣 + 벽시계 원 윤곽(바늘 2선) + 약병 작은 실루엣 + 지로 + add_glow 최소(눈만) + vignette. 가장 채도 낮은 컷.

### 컷 5 — 마당 (첫 외출·쏟아지는 햇살·마른 물그릇)
- **구도**
  - BG: **상단 절반이 환한 햇살** 하늘 그라데(첫 외출의 눈부심).
  - MG: 좌상(x0.05~0.40, y0.0~0.40) **라디얼 햇살 글로우**. 중경에 낮은 담장/현관 문턱 실루엣. 우하(x0.66, y0.70) **마른 물그릇**(빈, 바닥 갈라짐).
  - FG: 지로 문턱(x0.45, y0.60)에 서서 햇살을 향함. 바닥에 긴 그림자(우하 방향).
- **팔레트**: BG `#fbe7b0`(상, 환한 햇살)→`#e8b878`(중)→`#3a2c1c`(하) · 실루엣 `#1c140c` · 햇살 코어 `#fff8e0`(흰) · 글로우 트리거 `#fff8e0` + 지로 눈 `#9be84a`
- **광원**: 좌상 라디얼 태양(강·따뜻). apply_skylight 강하게.
- **지로/하루**: 지로 서서 햇살 응시, 눈 그린. 하루 없음 — 빈 물그릇이 '하루의 배려'를 상기(연속성).
- **분위기**: *세상은 환한데, 이 햇살을 하루 없이 처음 맞는다.*
- **PIL 힌트**: 따뜻한 노랑→갈 세로 그라데 + apply_skylight(color `(255,244,210)`, strength 0.3) + 좌상 라디얼 흰코어(큰 타원 GaussianBlur 8) + 담장/문턱 실루엣 + 마른 물그릇 작은 타원 실루엣(연속성) + 지로 + 우하 긴 그림자 타원 + add_glow + vignette(약 0.45, 밝은 컷).

### 컷 6 — 길거리 (두 줄→한 줄 발자국·황혼 가로등)
- **구도**
  - BG: **황혼 하늘** 그라데(보라→주황). 원근 소실점 중앙(x0.50, y0.45).
  - MG: 바닥 보도가 소실점으로 수렴. 보도 위 **발자국** — 가까이(하단)는 **두 줄(사람+고양이)**, 멀어질수록 **한 줄만** 남음. 좌우 가로등 2~3기(황혼 점등).
  - FG: 지로 화면 하단 중앙(x0.48, y0.64)에서 **소실점을 향해 걸어가는 옆모습**. 비네팅.
- **팔레트**: BG `#3a2c52`(상)→`#7a4e58`(중)→`#e0a060`(소실점 주황)→`#1a1018`(하) · 실루엣 `#140d12` · 가로등 코어 `#fff0c0`(흰)·번짐 `#ffcf78` · 글로우 트리거 `#fff0c0` + 지로 눈 `#34e2e2`
- **광원**: 소실점 황혼빛 + 가로등 점등(따뜻, 중). 가로등은 지면 헤일로 웅덩이(_draw_lamp 원리).
- **지로/하루**: 지로 걸음(옆모습). 하루 없음 — 발자국이 '함께→홀로'를 말함.
- **분위기**: *두 줄이던 발자국이, 어느새 한 줄이 됐다 — 그래도 계속 걷는다.*
- **PIL 힌트**: 보라→주황 세로 그라데 + 중앙 소실점 작은 흰코어 글로우 + 원근 보도(사다리꼴) + 발자국 점열(하단 2열 → 상단 1열) + 가로등 기둥 실루엣 + 지면 헤일로 타원(`(255,234,168,alpha)` 3겹) + 지로 옆모습 실루엣 + add_glow + vignette. 하단 발자국은 저대비로(텍스트 가독).

### 컷 7 — 상가 (카페 창의 따뜻한 추억)
- **구도**
  - BG: 저녁 거리 어둠.
  - MG: 우중(x0.45~0.85, y0.30~0.68) **카페 통창** — 따뜻한 실내빛이 새어나옴. 창 안에 **흐릿한 두 형체**(앉은 사람 + 무릎 위 작은 고양이) 실루엣.
  - FG: 지로 창 밖 보도(x0.30, y0.66)에 앉아 창을 올려다봄. 창빛이 보도에 따뜻한 웅덩이.

## 부록 — 엔지니어 빌드 체크리스트
- 네이티브 480×270 → NEAREST 업스케일(픽셀 보존, pixelart.py와 일관).
- 합성 순서(컷당): **BG 세로 그라데 → 실루엣(원경 blur 큰 것부터) → 광원 코어(흰/시안/그린, GaussianBlur) → apply_skylight(야외 5/9/12) → 지로 실루엣+눈 → 파티클/그림자 → add_glow → add_vignette**.
- **글로우 트리거**: 코어 hex가 add_glow 임계(시안 b·g>150 / 그린 g>170 / 흰 >210)를 넘는지 확인. 따뜻한 주황만으로는 약 → 코어를 흰/시안/그린으로 찍을 것.
- **하단 1/3(y>0.66)**: 저대비·저밀도 유지(텍스트 가독). 밝은 글로우는 가급적 중상단.
