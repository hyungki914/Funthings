# 상세 문서 ⑬ — 『잊혀진 발자국 / Lost Pawprint』 10스테이지 레벨/게임 디자인 스펙

> 상위: [GDD.md](../GDD.md) · 데이터 스키마: [game/data.js](../game/data.js) · 규칙 상수: [game/core.js](../game/core.js)
> 기존 3스테이지(지로의 방/집/공원)를 10스테이지로 확장. **본 문서의 모든 필드명·타입은 data.js 의 `DATA.chapterN` 스키마와 1:1 일치**시켜 작성했다.
> 좌표는 '의도 + 대략값'. 정확한 충돌 검산(가구 사각형 비겹침·patrol leg 비관통·spawn FREE)은 엔지니어가 수행한다.

## 0. 엔진/스키마 전제 (구현자 체크리스트)

- 타일 16px. 좌표 `[col,row]` 0-base. 사각형 `[c,r,w,h]` = cols `c..c+w-1` × rows `r..r+h-1`.
- `collision`: **앞 4개는 항상 테두리 벽** `[0,0,COLS,2]`,`[0,ROWS-1,COLS,1]`,`[0,0,1,ROWS]`,`[COLS-1,0,1,ROWS]` (기존 패턴 유지) + 이후 가구.
- `safeZones`: `[[c,r,w,h]]`. `door`: `{tile:[c,r], requires:'cores'}` (보통 상단 벽). `spawn:[c,r]` 는 어떤 collision 사각형에도 들지 않아야 함(FREE).
- `shards[]`: `{id, type:'core'|'echo'|'false', tile:[c,r], radius(1.2~1.3), identitySlot:0..4|null, recall:'...', hidden?:true}`. **core 만 identitySlot 부여**(0..4), echo/false 는 `null`. `gainMem/gainLight` 는 생략 가능(core.js 상수 우선: CORE_GAIN+2 / ECHO_GAIN+1 / FALSE_HIT-2).
- `murks[]`(시각): `{id, patrol:[[c,r],...] 닫힌 루프, speed(px/s), sightTiles(~3.3), fovDeg:90}`. `echoes[]`(청각): `{id, patrol, speed, hearTiles(~3.6)}`. **모든 patrol waypoint·leg 는 가구 비겹침**.
- 신규 권장 필드(구현 예정): `cols/rows` 가 뷰포트(≈22×14)보다 크면 카메라가 플레이어 추적. 세로 스크롤은 `rows>14`, 가로 스크롤은 `cols>22`. 작은 맵은 22×14 유지.
- 신규 per-stage 옵션: `controls[]`, `music`, `isFinal:true`, `ambient`(파티클 힌트 문자열 — 가벼운 연출 힌트). 기존 `identityLabels`,`epiphany` 패턴 계승.
- 자원 기준: `START_MEM=4`, `MEM_MAX=10`, `coresNeeded` 가 문을 게이트. 접촉 -2, iframe 1.2s. 보행 64 / 은신 38 px/s. `coresNeeded` 는 전 스테이지 3 유지(코어 항상 3개) — 난이도는 적/맵으로 조절.

## D) 연출 / 오디오 폴리시 권고 (가볍고 구현 가능한 것 위주)

**스테이지 전환**
- 페이드 아웃→인 0.6s + 다음 `title`·`music` 키 프리로드. 카메라 맵은 spawn 중심으로 즉시 클램프.
- 전환 시 하단에 스테이지 번호/제목 자막 1.5s(기존 epiphany 오버레이 재사용).

**조각 수집 FX (type별 색 언어 일관)**
- core: 시안 글로우 펄스 + 정체성 카드 슬롯 점등 + 회상 컷신(기존). 짧은 차임.
- echo: 약한 흰빛 링 1회 + 부드러운 톤(보상감, 컷신 없음).
- false: 잠깐 따뜻한 빛 → 직후 채도 급락·화면 미세 떨림 0.4s + 저음(메모리 -2 피드백). hidden 은 Q 비추기 시 윤곽 점등.

**환경 파티클 (ambient, 경량)**
- `dust`(실내): 느린 먼지 입자 소수. `leaves`(야외): 좌→우 낙엽 드리프트. `motes`(The Blank): 상승하는 빛 입자. 모두 알파 낮게·개수 제한(성능).

**스테이지별 BGM 분위기**
- 1 room: 따뜻·정적. 2 house: 잔잔+희미한 불안. 3 hall: 좁은 리버브·긴장. 4 quiet: 거의 무음+시계똑딱. 5 outdoor: 바람·새. 6 street: 도시 앰비언트·발걸음. 7 arcade: 형광등 험·미로감. 8 gate: 리듬 타악 긴장. 9 park: 9챕터 톤 확장·최대 긴장 빌드. 10 blank: 미니멀 드론·해소.
- 미터 2칸 이하: 저음 드론 레이어 추가 + 적 속도 체감 +10%(연출). 안전지대 진입: 하이패스 해제로 '숨통' 사운드.

**카메라 연출**
- 세로/가로 스크롤 맵(3,6,9)은 플레이어 추적 + 맵 경계 클램프, 데드존 ±2타일(미세 흔들림 방지).
- 적 CHASE 진입 시 카메라 살짝 줌인(1.0→1.05) + 비네팅 강화. door 개방 시 문 방향 0.5s 팬.
- The Blank(10): 최종 비추기 순간 천천히 줌아웃하며 좌대→플레이어 실루엣 겹침 연출.

**구현 경량 원칙:** 모든 FX 는 캔버스 알파/스케일/짧은 타이머 기반(셰이더·물리 없음). ambient 입자는 스테이지당 ≤24개. 파티클·드론은 접근성 '긴장 완화' 토글로 약화 가능하게.
