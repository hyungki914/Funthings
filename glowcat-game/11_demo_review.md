# 11 · 데모 시연 & 교차직군 리뷰 — 챕터1 VS (반영 완료)

> 트리거: 실제 플레이테스트 피드백 — **"플레이는 되는데 뭘 하는지·뭘 할 수 있는지·제대로 하는지 하나도 모르겠다."**
> 방식: 현재 플레이 빌드(`game/`)를 3개 직군 리뷰어가 코드 단위로 검토 → P0 수렴 → 즉시 반영.

## 1. 리뷰 요약 (현재 빌드 기준)

| 직군 | 한 줄 |
|---|---|
| **FTUE/UX** | "시스템은 다 만들어졌는데 **가르치는 레이어가 0**. 이미 있는 L(길안내)·Q(숨은조각)·일지(체크리스트)를 첫 60초에 보이게 하면 해결." |
| **게임 디자인** | "**가르치는 층(온보딩)과 전진을 알리는 층(진행 피드백)이 통째로 비어** 뭘/왜/제대로 하는지 모르는 건 당연한 결과." |
| **QA(신규 첫 3분)** | "단위테스트는 녹색인데 **통합에서 Murk가 실명(FOV 이중변환 버그)**. + 스폰 최근접이 함정 조각이라 첫 행동이 처벌." |

**3개 리뷰가 독립적으로 동일한 P0에 수렴** = 신뢰도 최상.

## 2. QA가 잡은 실제 버그 (★)
- **Murk 시야각 이중 변환:** `main.js`가 `fov`를 라디안으로 넘기고 `core.js`가 다시 도→라디안 변환 → 90° 시야가 **~1.6°로 붕괴 = 적이 사실상 실명**. 단위테스트는 도(°)로 호출해 통과 → **통합에서만 깨짐**(계약 불일치).
- 부수: 좌하단 "빛" 라벨 중복(dead code), 후퇴 시 순간이동 인과 불명 등.

## 3. 반영한 P0 (이번 빌드에 적용 완료)

| # | 개선 | 효과 |
|---|---|---|
| 1 | **[버그] Murk FOV 라디안→도 수정** + 스모크에 측면 회귀 케이스 추가 | 적이 제대로 보고 추격 → 스텔스/긴장 작동 |
| 2 | **목표 배너(상단 상시)** "목표 · 코어 기억 ●○○ — 빛나는 기억에 다가가 [E]" → 3/3 시 "문이 열렸다 ↑" + 문 화살표 | "뭘 하는지" 즉시 해결, 목표 위계 단일화 |
| 3 | **L 코치마크**(무입력 3초 시 캐릭터 위 "[L] 발자국 추적 — 흔적을 따라가자") | 빈 방 문제 직격(가장 강력한 길안내를 가르침) |
| 4 | **환경 단서**(미발견 조각을 거리 비례 흐릿하게, 거짓은 차갑게 깜빡) | 글로우 OFF의 "빈 방"감 해소 + 거짓 사전 단서 |
| 5 | **획득 피드백 토스트** "코어 2/3 회복!"·"에코"·"⚠ 거짓된 기억 손실" + 카운터 펄스 | "제대로 하고 있나" 진행감 |
| 6 | **Murk 시야콘 시각화**(평시 보라/추격 빨강) + 첫 감지 시 "들켰다! [Shift] 은신" 토스트 | 왜 들켰는지 보임(스텔스 공정성) |
| 7 | **후퇴 메시지** "방금 떠올린 기억이 다시 어둠에… 같은 자리에서 되찾을 수 있다" | 손실회피 분노 → 긴장으로 전환 |
| 8 | **인게임 조작 힌트**(하단) + HUD 대비 상향 + "빛=생명/후퇴" 라벨, 중복 라벨 제거 | 화면 밖 안내 미인지 해소 |
| 9 | **함정 조각 재배치**([13,11]→[16,11], 스폰 최근접 탈피) | 첫 행동이 처벌받지 않음 |

## 4. 검증
- `node --test core.test.mjs` 17/17 · `node smoke.mjs`(**FOV 회귀 케이스 포함**) OK · `node headless.mjs` 700프레임 무예외 · `verify_standalone.mjs` 400프레임 무예외 · 7개 JS 문법 OK.

## 5. 남은 백로그 (다음 스프린트)
- **P1:** Q(비추기) 강제 학습 비트(숨은 에코 발견 보장) · 동사 점진 해금(챕터1=L 중심, Q는 선택보상) · 일지 "다음에 할 일" 능동 힌트 · 메모리 감소 원인 분리(접촉 -2 팝업 vs 자연감소) · 환경 단서를 data 스키마(`clue`)로 정식화.
- **P2:** 광과민성 토글(현재 flash/shake 무조건) · 설정 화면 · 마우스 포인트앤클릭 이동(GDD 4-2 약속분) · 게임패드 매핑 · 정체성 카드 패시브 실연동.
