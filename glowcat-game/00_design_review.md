# 00 · 교차직군 디자인 리뷰 & 의사결정 로그 (v2.0 개정 기준)

> 대상: 『잊혀진 발자국 (Lost Pawprint)』 v1 기획 산출물 전체
> 방식: 6개 직군(게임디자인/내러티브/레벨/아트·UX/테크/프로듀서) 독립 리뷰 → 리드 종합 → 충돌 조율 → 의사결정 확정
> 이 문서가 **상위 결정 문서(SSOT)** 입니다. GDD 및 01~05 문서는 여기서 확정한 결정(D1~D9)을 따릅니다.

## 1. 리뷰 요약 (스코어카드)

| 직군 | 점수 | 한 줄 평 |
|---|---|---|
| 내러티브 디자인 | **7.0** / 10 | 시스템-테마 통합은 발군. 반전 클리셰·신파·루프엔딩 처벌감이 발목 |
| 게임 디자인(시스템) | 5.5 / 10 | "각본은 완성, 게임은 미시작" — 코어 동사 2개·미터 이중역할 결함 |
| 레벨 디자인 | 5.5 / 10 | 맵이 '읽히는 그림'일 뿐, 스텔스의 기하학이 수치로 안 닫힘 |
| 아트 · UX | 5.5 / 10 | 무드 7.5점이나 시점 충돌·접근성·디자인시스템·누락화면 |
| 프로듀서 · 비즈니스 | 5.5 / 10 | 기획 상위10% / 사업 하위10%. 스코프 2~3배 과대 |
| 테크니컬 | **3.5** / 10 | "만들 수 있는 문서"가 비어 있음. 엔진·스키마·세이브 전무 |
| **종합** | **≈5.5 / 10** | 콘셉트·서사 자산은 출시작급, 그러나 *플레이어블*과 *프로덕션 실행*은 미착수 |

**총평:** 강점은 진짜다 — 시장 검증된 콘셉트 교집합(고양이 + 기억상실 미스터리 + 사물 서사), 메커닉-내러티브 통합. 약점도 진짜다 — 손가락이 하는 일(코어 동사)이 빈약하고, 엔진/아키텍처/사업 결정이 통째로 비었으며, 스코프가 인디 규모의 2~3배다. **전부 "추가/축소로 고칠 수 있는" 문제이지 회복 불가 결함이 아니다.**

## 2. 교차직군 수렴 지점 (여러 리뷰어가 독립적으로 같은 결론)

전문가들이 서로 모르고 같은 처방을 낸 항목 = 신뢰도 최상, 최우선 반영.

1. **하드 리셋(0칸→처음부터)은 폐기/완화해야 한다.** — 게임디자인(손실 회피=분노), 내러티브(루프엔딩이 처벌로 읽힘), 프로듀서(R2 환불 리스크), 테크(영구/세션 상태 경계 위험). **4개 직군 수렴.**
2. **메모리 미터의 "재화이자 생명" 이중역할은 결함이다.** — 게임디자인(힌트가 죽은 시스템 됨), 아트·UX(0.5칸 표현 불가·가독성). **2개 직군 수렴 → 2게이지 분리.**
3. **스코프를 줄여 수직 슬라이스부터 검증하라.** — 프로듀서(5챕터→3, 2~3배 과대), 게임디자인(코어 검증 전 챕터3~5 만들지 마라), 테크(P0=수직 슬라이스). **3개 직군 수렴.**
4. **맵을 정량화하고 시스템과 합동 검증하라.** — 레벨(플레이어 속도·순찰 좌표·통로폭), 게임디자인(글로우 OFF+공간 깊이), 테크(타일↔엔진 좌표 계약). **3개 직군 수렴.**
5. **반전/서사는 telegraph와 절제가 필요하다.** — 내러티브(분산 복선·독백 절제), 게임디자인("재해석 재생"을 손과 연결). **2개 직군 수렴.**

## 3. 의사결정 로그 (D1~D9) — 확정

각 결정 = [무엇을] / [왜] / [출처 직군] / [영향 문서] / [해소한 충돌].

### D1 · 메모리 시스템 재설계 — 2게이지 + "후퇴(Setback)"
- **[무엇을]** 단일 미터를 둘로 분리.
  - **메모리 미터(생명/페이싱):** 0칸 도달 시 *하드 리셋이 아니라* **후퇴(Setback)** — 마지막 안전지대 체크포인트로 귀환 + 가장 최근 코어 회상 1개 *임시 봉인*(같은 자리에서 재획득 가능, 위치 표시) + 30초 최대 왜곡 연출. **코어 기억은 영구 보존**(다시 안 잃음). 힌트로는 깎이지 않음.
  - **빛 자원(Light, 재화):** 코어/에코로 충전되는 별도 소모 자원. 힌트·거짓 판별·비상 빛 웅덩이·"기억 비추기"에 사용.
- **[왜]** 한 자원에 생명+재화를 묶으면 최적전략이 "힌트 절대 금지"로 수렴해 도움 시스템이 죽고, 하드 리셋은 추리 흐름·위치·15분을 빼앗아 *긴장이 아니라 분노*가 된다(손실 회피). 표준 모드 기본을 후퇴로 두면 좌절을 제거하면서 "다시 잊는다"는 테마는 *매 후퇴 시 오프닝 독백 반복*으로 오히려 더 자주 체험된다.
- **[출처]** 게임디자인(주), 내러티브, 프로듀서, 테크.
- **[영향]** 03(미터 1·5절 전면), 01(루프엔딩 6-4), GDD(5절), 04(3계층 세이브), 05(R2).
- **[해소한 충돌 C1]** "리셋=루프엔딩 복선"(작가) vs "환불 리스크"(사업). → **하드 리셋을 옵트인 '서스펜스 모드' 전용으로 격리**, 표준은 후퇴. 둘 다 만족.

### D2 · 코어 동사 확장 — 기억 비추기 + 발자국 추적 (글로우 OFF, 3단 발견)
- **[무엇을]** "걷기+줍기" 2개뿐이던 동사에 능동 동사 2개 추가:
  - **기억 비추기(Memory Projection):** 장착한 코어 기억의 빛을 환경에 비추면 그 기억과 연관된 숨은 오브젝트/통로가 드러남. "어떤 렌즈를 들까"라는 의사결정.
  - **발자국 추적(Pawprint Trail):** 홀드 시 시안색 흔적/냄새 잔향이 떠올라 조각의 출처를 따라감. 거짓 조각은 흔적이 *끊기거나 차갑다*(추리 단서 결합). **게임 제목 'Lost Pawprint'와 직결되는 시그니처.**
  - (물리 상호작용 1종 — 밀기/올라가기/떨어뜨려 소리내기 — 검토 대상.)
  - **글로우는 기본 OFF.** 찾기 = "환경 단서 → 상호작용 → 회상"의 3단 발견.
- **[왜]** 핵심 동사가 재미없으면 어떤 서사 포장도 게임을 못 구한다. "글로우 보고 직진"은 찾기의 인지 노동을 0으로 만든다.
- **[출처]** 게임디자인(주), 아트·UX(다이제틱 시그니처), 레벨.
- **[영향]** GDD(4절), 03(동사·발견), 02(맵 재배치), 04(데이터·회상 트리거).
- **[충돌 C5]** 글로우 OFF+3단 발견은 맵 재설계(레벨)·신규 데이터(테크)·신규 비주얼(아트)을 동시 요구 → **수직 슬라이스에서 합동 구현·검증.**

### D3 · 스코프 컷 — v1.0 정의
- **[무엇을]**
  - **챕터 5 → 3** (방→집→공원). '마당'은 집 후반부로 흡수, '비밀장소'는 공원 클라이맥스로 압축.
  - **적 3종 → 2종** (Murk 시각 + Echo 청각). 보스 The Blank는 유지하되 **1페이즈로** 단순화(3페이즈=포스트런치).
  - **난이도 3종 → 2종** (스토리/표준). 서스펜스 모드=포스트런치(D1의 하드리셋도 여기).
  - **뉴게임+ / 키보드+터치 동시지원 = 포스트런치.** v1.0은 **PC(키보드+게임패드+마우스 포인트앤클릭) 우선**, 순수 터치는 모바일 포트로 분리.
  - **MVP = 버티컬 슬라이스 = 챕터1 완성 + 챕터2 도입** (데모/위시리스트/플레이테스트 단위).
  - 컷한 것은 폐기가 아니라 **포스트런치 무료 업데이트 로드맵**으로 스토어 노출.
- **[왜]** 회상 컷신 19개 = 사실상 미니 단편 19편, 5개 고유 아트셋. 2인 인디가 1년에 못 끝낸다. 두 입력 동시지원은 QA·UX가 두 벌.
- **[출처]** 프로듀서(주), 게임디자인, 테크.
- **[영향]** GDD(전반·로드맵), 01/02(챕터 재편), 05(마일스톤·예산).
- **[충돌 C2]** 챕터 5→3이 작가의 3단 반전 구조를 건드림. → **반전 3단은 유지하되 챕터에 재분배**(방=표층, 집=중층진입, 공원=중층절정+심층). 어느 회상을 살리고 어느 걸 에코(선택)로 강등할지 작가-프로듀서 협상.
- **[충돌 C3]** "키보드+터치 항상 동시활성"(UX 접근성 기둥) vs PC 우선(사업). → **v1.0은 마우스 포인트앤클릭+게임패드까지 지원**(한손/원클릭 접근성 상당부분 충족), 순수 터치스크린은 포스트런치.

### D4 · 시점 확정 — 인게임 3/4 쿼터뷰 + 초상 전용 정면 치비
- **[무엇을]** 인게임 캐릭터는 **3/4 쿼터뷰**(Stray식)로 확정. 등·귀·꼬리의 시안 글로우는 보이고 살짝 든 고개로 눈도 일부. 눈 안 보이는 각도는 **다이제틱 시그니처**로 보완: 이동 시 바닥 시안 발자국 트레일(D2와 결합), 머리 위 떠다니는 발바닥, 시안 림라이트. **현재 정면 치비는 메뉴/정체성카드/회상/대화 '초상화 전용'.**
- **[왜]** 탑다운 게임뷰에 정면 치비를 얹으면 한 화면에 3시점이 섞이고, 4/8방향 이동·시야 회피가 성립 안 함. 정면 치비를 인게임 표현인 척하는 게 현 목업의 가장 큰 거짓말.
- **[출처]** 아트·UX(주).
- **[영향]** 목업 전반, GDD(8절), 04(스프라이트), 05(아트 공수=최대 병목).
- **[의존]** 시점 확정 전엔 애니메이터가 워크사이클/방향셋 못 만듦 → **즉시 잠금**, 쿼터뷰 모델시트 우선 발주.

### D5 · 엔진 = Godot 4.x (조건부) + 한/영 폰트 스파이크 P0 최우선
- **[무엇을]** **Godot 4** 채택(2D 타일맵·AStarGrid2D·InputMap·Resource·세이브 내장, MIT 무료). 타입세이프 강제(GDScript static typing 또는 C#). **단, 착수 직후 최우선으로 "한/영 폰트 스파이크"**: Noto Sans KR DynamicFont를 PC/모바일/(웹)에 띄워 글리프·커서·로케일 검증. 실패 시 웹만 Phaser+웹폰트로 폴백.
- **[왜]** 엔진은 모든 기술 결정의 부모 노드. Godot가 이 프로젝트(2D·터치+키보드·내러티브·소규모)에 최적이나, **CJK/HTML5 폰트 버그가 실재**하고 이 게임은 텍스트가 주 서사 매체.
- **[출처]** 테크(주), 프로듀서(동의).
- **[영향]** 04 전반, 05(빌드).

### D6 · 기술 5대 기둥 (P0 선행 — 직군 간 인터페이스 계약)
- **[무엇을]** ① **데이터 주도 스키마 5종**(MemoryShard/Cutscene/EnemyArchetype/맵-spawns/i18n) + 로더 검증. ② **3계층 세이브**(meta/permanent/run) + save_version 마이그레이션. ③ **입력 Intent 추상화 + 그리드 A\*** (탭→경로이동). ④ **GameState 싱글톤(SSOT)** + 시그널. ⑤ **AI 인지 알고리즘**(시각 3단 게이트: 거리/각도/LoS, Echo는 소리 이벤트 발신·구독).
- **[왜]** 이 5개가 없으면 엔지니어가 임의 결정 100개를 내리고 그게 내러티브·레벨·밸런싱 작업과 충돌. 먼저 합의하면 팀이 코드 안 건드리고 병렬로 달림.
- **[출처]** 테크(주).
- **[영향]** 04 전반, 01/02/03(전부 데이터화 대상).

### D7 · 레벨 정량화 + 02↔03 합동 오버레이 검증
- **[무엇을]** ① **플레이어 속도 확정**(보행 3.2 / 은신 1.9 타일/s)을 모든 적 속도의 기준으로. "Echo 추격 3.0 < 보행 3.2" 보장 + "발각 시 빛 웅덩이까지 ≤4타일" 룰. ② **순찰 경로를 웨이포인트+속도+위상**으로 정의("안전 윈도우 ≥ 통과시간+1초" 공식). ③ **통로 폭 ≥ 시야반경+2(≈6타일)** + 커버 라인. ④ **모든 조각/키 좌표 완전 마킹** + 락-키 도달성(BFS) 검증. ⑤ **회복(+0.5/s) vs 위험 자연감소(-0.05/s) 10:1 불균형 재밸런스**(감소 -0.15~-0.25). ⑥ 맵 위에 시야콘/청각원/순찰선을 실측 스케일로 **오버레이 검증 패스**.
- **[왜]** 플레이어 속도가 없어 "도망칠 수 있는가"가 미정. 시야 3.5 vs 통로 3~5타일이면 우회로가 물리적으로 불가능 = 스텔스가 아니라 타이밍 암기.
- **[출처]** 레벨(주), 게임디자인.
- **[영향]** 02 전반, 03(수치).
- **[충돌 C4]** 챕터(최종) 안전지대 0 vs 후퇴는 안전지대로 귀환(D1). → 최종 챕터는 **"이동 안전지대"**(고양이가 비춘 빛이 만드는 일시 웅덩이)로.

### D8 · 내러티브 정련
- **[무엇을]**
  - **반전 ③"적=나"를 선언이 아니라 챕터 누적 복선으로 분산:** (집)안 덤비고 따라만 다니는 Murk 1체 / (집·공원)빛 웅덩이에서 *물에 비친 내 그림자가 한 박자 늦게/안개처럼* 흔들림 / (공원)거짓 조각 주울 때 *그 거짓을 만드는 검은 발=내 발*이 0.5초 비침. → 반전을 *수긍*으로.
  - **반전 ②를 "판타지 특별함"→"관계의 특별함"으로 재정의:** 청록 무늬는 *하루를 떠올릴 때만* 빛난다(=하루가 남긴 것). ②가 ③의 복선이 되어 두 반전이 한 줄로 꿰임.
  - **신파 방지:** 결정적 독백의 직접진술 제거 — "스스로 지웠어"→플레이어가 *직접* 조각을 안개에 밀어넣는 회상으로, "미안해" 녹음→끊긴 자동응답("…금방 올게")로 추상화, 주제 3중 진술→**1회 이하**(가능하면 무언 엔딩).
  - **독백 예산제:** 챕터당 상한, 정체성이 또렷해질수록 독백 *개수 감소*("말 없는 주인공" 컨셉과 실행 일치).
  - **거짓 조각 = 그리프의 부정(denial) 단계:** 잠깐의 진짜 위안 + 그 속의 진실 파편(시든 꽃·멈춘 달력) + 후반 독백 자체의 자기기만(극적 아이러니).
  - **엔딩 비처벌화:** 진엔딩 해금에서 수행 게이트(거짓 0개) **제거**, **마지막 선택만으로 분기**. 루프 엔딩에 "사랑의 잔향" 여운 추가, 뉴게임+ 해금은 엔딩 연출과 분리. 두 엔딩 톤 대칭(둘 다 '사랑의 다른 얼굴').
  - **사물 상태 서사:** 밥그릇 2개(하나는 사람용 컵)·한쪽만 꺼진 침대·특정 날짜에 멈춘 달력 등 '줍기 전에 읽히는' 단서 챕터당 ≥2.
- **[왜]** ②③이 클리셰 정중앙. 슬픔을 독백이 결론으로 떠먹이면 정서적 소유권이 사라짐. 루프엔딩을 시스템이 처벌하면 게임이 자기 테마("잊는 것도 사랑인가")를 배신.
- **[출처]** 내러티브(주), 게임디자인.
- **[영향]** 01 전반, 02(서사 트리거 레이어·분기로직), 03(거짓조각 2단연출·PASSIVE Murk 상태).
- **[충돌 C2 연계]** 진엔딩 "거짓 0개" 게이트 제거 → 02 §4의 "거짓 0개=진엔딩 가산점" 분기 **무효화**(거짓 조각은 미터 압박+환각 강화 기능만 유지).

### D9 · UX / 접근성 정련
- **[무엇을]**
  - **메모리 미터 재설계:** 칸 토큰을 `empty/half/full/danger` **4상태**(0.5칸=반쪽 발바닥), 5+5 그룹핑 또는 색 계조, 위험 시 **형태 변화**(금/흩어짐)로 색약자도 인지.
  - **색+형태 이중 인코딩:** 완료=연두 ✓(형태), 진행=점선+%, 잠금=자물쇠. 적은 색이 아니라 **실루엣/모션**(Murk=뭉게짐, Echo=흩날림)으로. 시안=중립UI / 연두=긍정·해금 **역할 고정**.
  - **대비 수정:** 잠금/캡션 텍스트 최소 3:1(본문 4.5:1). (현재 2.45/2.50:1 미달.)
  - **광과민성 가드:** 플리커 <3Hz, 적색 고채도 번쩍임 회피, **'화면 흔들림 감소'·'플래시 감소'·'색수차 끄기' 옵션 P0.**
  - **누락 화면 신설(우선순위):** 기억 일지/추리 보드(미스터리 본체!), 설정/접근성, 온보딩/튜토리얼, 엔딩 2종, 후퇴(0칸) 화면, 일시정지, 상호작용/자물쇠 패널, 맵.
  - **디자인 토큰 + 컴포넌트화:** 색/타이포/스페이싱/라운드/글로우 토큰, 미터칸·슬롯·토스트·버튼·초상 컴포넌트, 상태 정의, 터치 타깃 44px.
  - **표기 통일:** 정체성 진행이 정체성카드(3/5)와 HUD(1/5)에서 **불일치** → 단일 GameState 질의로 통일.
- **[출처]** 아트·UX(주), 테크(SSOT).
- **[영향]** 목업 전반, GDD(9절), 04(UI 프레임워크), 05(인증·심사 리스크).
