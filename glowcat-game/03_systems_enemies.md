## ⚙ v2.0 개정 반영 (교차직군 리뷰 → [00 결정 로그](./00_design_review.md))

> 아래 원문(§1~§8)은 v1 설계다. **충돌 시 본 개정 블록이 우선**한다. 핵심 변경:
>
> 1. **단일 미터 → 2게이지 (D1).** §1·§4·§5의 "메모리 미터가 생명+재화 겸용"은 **결함**으로 폐기.
>    - **메모리 미터(생명/페이싱):** 접촉·거짓조각·위험지역으로만 감소. **힌트로는 감소하지 않음.** 코어 +1칸, 안전지대 회복.
>    - **빛 자원(Light, 재화) [신설]:** 코어/에코로 충전. 힌트·거짓판별·비상 빛웅덩이·**기억 비추기**에 소모. → §4 "힌트 -0.5칸"은 **"빛 1 소모"로 대체.**
> 2. **0칸 = 후퇴(Setback), 하드 리셋 폐기 (D1).** §1-3의 "표준=챕터 처음부터"는 **표준=마지막 안전지대 귀환 + 최근 코어 1개 임시봉인(재획득 가능) + 30초 왜곡연출**로 교체. **코어 기억 영구 보존.** 하드 리셋은 **옵트인 서스펜스 모드(포스트런치)** 전용.
> 3. **임계 연출 분리 (D1).** §1-2의 흑백·왜곡은 미터가 아니라 별도 **'기억 안정도(Clarity)'** 값(위험지역 체류·거짓조각 누적)에 연동 → 저기억 연출을 *감상 가능*하게.
> 4. **플레이어 속도 확정 (D7).** 보행 **3.2** / 은신 **1.9** 타일/s. 모든 적 속도의 기준. **"Echo 추격 3.0 < 보행 3.2" 보장** + "발각 시 빛웅덩이까지 ≤4타일" 룰.
> 5. **위험지역 자연감소 재밸런스 (D7).** §1-1의 -0.05칸/s는 회복(+0.5/s)의 1/10이라 무력 → **-0.15~-0.25칸/s**로 상향(또는 안전지대 회복 하향).
> 6. **인지 알고리즘·데이터화 (D6).** §2 FSM의 *판정 알고리즘*을 명시: 시각=3단 게이트(거리/각도/LoS), Echo=**소리 이벤트 발신·구독 모델**. 적 스탯은 `EnemyArchetype` 데이터로 분리(코드 하드코딩 금지). → 상세 [04 §6](./04_technical_design.md).
> 7. **거짓 조각 2단 연출 + PASSIVE Murk (D8).** 거짓 조각 = "잠깐의 위안 → 직후 왜곡"의 2단 + 진실 파편 포함. 챕터2에 거짓 1개 선(先)도입(0→1→2 대신 **1→2→다수**). "안 덤비는 Murk"용 **PASSIVE 상태**를 Murk FSM에 추가(적=나 복선).
> 8. **코어 동사 추가 (D2).** "기억 비추기/발자국 추적"이 상시 동사. 회상 트리거가 *줍는 순간* 외에 *비추는 순간*에도 발생 가능 → §7 상태 다이어그램에 반영.

## 1. 메모리 미터 (핵심 시스템 수치화)  *(※ v1 — 위 개정 블록 D1·D7 우선 적용)*

- **총 10칸.** 1칸 = 100pt → 총 1000pt 내부 관리(부드러운 게이지 연출용).
- **시작값:** 챕터1 진입 시 **4칸(400pt)**. 이후 챕터는 직전 종료값 계승(최소 보장 3칸으로 보정).

### 1-1. 변동 이벤트
| 이벤트 | 변동 | 비고 |
|---|---|---|
| 코어 조각 수집 | **+1칸(+100)** | 챕터 진행의 주 회복원 |
| 에코 조각 수집 | +0.3칸(+30) | 소소한 보상 |
| 거짓 조각 수집 | **-1칸(-100)** | + 화면 왜곡 2초 |
| 적 접촉(Murk) | -1칸(-100) | 접촉 후 1.5초 무적(연속 피해 방지) |
| 적 접촉(Echo 포획) | -1.5칸(-150) | Echo는 더 위험 |
| 보스 그랩(The Blank) | -2칸(-200) | 페이즈당 1회 한정 |
| 힌트 '직감' 사용 | -0.5칸(-50) | 가장 가까운 코어 방향 2초 표시 |
| 거짓 판별 힌트 | -0.5칸(-50) | 조각의 진/거짓 1회 판정 |
| 안전지대 휴식 | **+0.5칸/초(+50/s)** | 적 비접근 시에만 |
| 위험지역 자연감소 | -0.05칸/초 | 챕터4·5 한정(서스펜스) |

### 1-2. 임계 연출(서스펜스)
| 잔량 | 연출 |
|---|---|
| 4칸 이하 | 화면 가장자리 옅은 흑백 비네팅 시작 |
| 2칸 이하 | 채도 급감 + 저음 드론 + 적 이동속도 +10% |
| 1칸 | 심장박동 SFX, 화면 떨림, 거짓 환각 1개 무작위 출현 |
| **0칸 = 완전 망각** | 리셋 시퀀스(아래) |

### 1-3. 0칸 리셋 (사용자의 "다 쓰면 처음부터")
```
[연출] 화면이 검게 빨려들어가고 오프닝 독백 "…어둡다. 여기는…" 재생.
[규칙] 표준: 현재 챕터 처음으로 리셋. 단 영구 해금된 '확정 기억(코어 조각)'은 일지에 보존,
        해당 회상 컷신은 재시작 시 스킵 가능 → 학습 진행은 지키고 위치/적 상태만 초기화.
[서스펜스 모드] 게임 전체 처음으로 리셋(하드).
[스토리 모드] 리셋 없음. 0칸 도달 시 가장 가까운 안전지대로 강제 귀환 + 적 일시 후퇴.
```
> **내러티브 통합:** 이 리셋 경험이 챕터5 '루프 엔딩'의 감정 복선이 된다(문서 ① 6-4).

## 2. 적(망각 존재) 로스터 & AI 상태머신

공통: 모든 적은 **빛 웅덩이(☼)에 진입 불가**, 안전지대 반경 침범 불가. 직접 전투 없음 — **회피·은신** 중심.

### 2-1. 그림자 안개 (Murk) — 시각 감지형
- **역할:** 기본 위협. 정해진 경로 순찰, 시야에 들면 추격.
- **수치:** 순찰 1.8타일/s, 추격 2.6타일/s, 시야 반경 3.5타일·전방 90° 부채꼴, 추격 포기 4초.
- **상태머신:**
```
PATROL  ──(고양이 시야 내 & 비은신)──▶ CHASE
PATROL  ──(빛/안전지대 접근)──▶ PATROL(우회)
CHASE   ──(접촉)──▶ 미터 -1 → 고양이 1.5s 무적 → COOLDOWN
CHASE   ──(시야 상실 4s)──▶ RETURN(마지막 목격 지점 수색) ──▶ PATROL
COOLDOWN(2s) ──▶ PATROL
```
- **약점:** 은신(Shift) 중이면 시야 반경 60% 축소. 빛 웅덩이 뒤로 돌면 즉시 시야 차단.

### 2-2. 속삭이는 잔상 (Echo) — 청각 감지형
- **역할:** 스텔스 강제. 시야가 아니라 **소리**에 반응.
- **수치:** 배회 1.5타일/s, 추격 3.0타일/s(빠름), 청각 반경 = **소음 레벨에 비례**.
- **소음 레벨 모델:**
| 행동 | 소음 반경 |
|---|---|
| 은신 이동(Shift) | 1.0타일 |
| 일반 이동 | 2.5타일 |
| 젖은 바닥(≈) 일반 이동 | 4.5타일 |
| 물건 줍기/서랍 | 순간 3.0타일(0.5s) |
| 정지 | 0타일(감지 불가) |
- **상태머신:**
```
WANDER ──(소음반경 내 발생)──▶ INVESTIGATE(소리 지점으로)
INVESTIGATE ──(2s내 추가 소음)──▶ CHASE
INVESTIGATE ──(소음 없음 3s)──▶ WANDER
CHASE ──(포획)──▶ 미터 -1.5 → 고양이 잠깐 속박(0.8s) ──▶ COOLDOWN
CHASE ──(고양이 정지 & 무소음 2s)──▶ LOSE ──▶ WANDER
```
- **공략:** 멈춰서 지나가길 기다리거나(정지=무소음), 일부러 먼 곳에 소리(던질 수 있는 '소리 미끼' 아이템)로 유인.

### 2-3. 공백 (The Blank) — 보스 (챕터5)
- **역할:** 완전한 망각의 화신. 고양이의 거대 그림자 형상. 챕터5 중앙 고정, 3페이즈.
- **메커니즘:** 직접 데미지 대신 **기억을 빼앗으려** 그랩. 고양이가 모은 **코어 조각 3개의 빛**을 차례로 비추어 약화.
```
PHASE 1: The Blank가 맵에 환각(거짓 조각) 소환, 코어 ★1 주변 안개로 가림.
         → 플레이어가 진짜 ★1 획득 후 보스에게 '비추기'(E) → 보스 1/3 약화, 안개 일부 소산.
PHASE 2: 보스가 '그랩 촉수' 사용(예고선 1s 후 직선 돌진, 회피 가능). ★2 획득→비추기.
         그랩 적중 시 미터 -2 + 정체성 카드 일시 흐려짐(연출).
PHASE 3: 화면 거의 흑백, 환각 다수. ★3 획득→비추기 → 보스 정지.
         → 보스 실루엣이 고양이와 포개지며 "…너는 나였구나" → 최종 선택 트리거.
```
- **공정성 규칙:** 그랩은 항상 예고선 + 회피 가능 시간 보장. 페이즈마다 안전 코너 1곳 일시 생성(완전 무자비 방지).

## 3. 은신 시스템 (Stealth)
- **입력:** Shift 홀드(키보드) / 화면 하단 🐾 버튼 홀드(터치). 이동속도 -40%, 소음 반경 대폭 감소(2-2 표).
- **시각 피드백:** 은신 시 고양이 외곽의 시안 글로우가 흐려지고 발끝만 빛남 → "조용함"을 색으로 전달.
- **트레이드오프:** 느려서 추격 시작되면 불리 → "걸리기 전에 숨기"가 정석. 발각 후엔 빛 웅덩이로 도망이 정답.

## 4. 힌트·아이템 경제 (리스크-보상)
| 요소 | 비용 | 효과 | 설계 의도 |
|---|---|---|---|
| 직감 힌트 | -0.5칸 | 가장 가까운 미발견 코어 방향 화살표 2s | 막힘 해소 vs 미터 압박 |
| 거짓 판별 힌트 | -0.5칸 | 조준한 조각의 진/거짓 표시 | 추리 보조(챕터4·5) |
| 소리 미끼(획득형) | 무료(수량 제한) | 던진 지점에 소음 발생→Echo 유인 | 스텔스 능동 공략 |
| 빛 조각(소모형) | 무료(희귀) | 일시 빛 웅덩이 생성 3s | 비상 탈출 |
> 미터를 "재화이자 생명"으로 이중 사용 → 모든 힌트 사용이 긴장과 직결되는 미스터리·서스펜스 핵심 루프.

## 8. 프로토타입(P0) 최소 구현 범위 — 우선순위
1. 탑다운 이동(키보드+탭) + 충돌 + 카메라.
2. 조사/줍기 → 코어 조각 1개 → 회상 컷신 1개 → 정체성 UI ? 변화.
3. 메모리 미터(증감·0칸 리셋) HUD.
4. Murk 1마리(PATROL/CHASE/접촉 피해) + 빛 웅덩이 회피.
5. 챕터1 '내 방' 맵(문서 ② 1절) 1구역으로 수직 슬라이스 완성.
> 이 5개만으로 핵심 재미(탐험→발견→회복→회피)의 검증이 가능.
