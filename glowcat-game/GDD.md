# 게임 기획서 (GDD) — 『잊혀진 발자국 (Lost Pawprint)』

> 가제: **Lost Pawprint** / 한글명 후보: 『잊혀진 발자국』, 『아홉 번째 기억』, 『이름 없는 고양이』
> 장르: 미스터리·서스펜스 + 탑다운 탐험 + 히든 오브젝트(숨은 물건 찾기)
> 플랫폼: PC(키보드) / 터치 기기(태블릿·노트북 터치패드) 겸용 — 2D 탑다운
> 타깃: 잔잔하지만 긴장감 있는 1인용 내러티브 게임을 좋아하는 플레이어
> 1회차 플레이 타임: 약 2~4시간 (챕터 5개 기준)

---

## 0. 한 줄 소개

> **"눈을 떴을 때, 나는 내가 누구인지 몰랐다. 흩어진 물건 하나하나가 나를 다시 만들어 간다 — 기억을 모두 잃기 전에."**

기억을 잃은 검은 고양이가 방 → 집 → 바깥세상을 돌아다니며 **숨겨진 물건을 찾아 기억 조각을 되찾고**, 자신의 정체와 **'왜 기억을 잃었는가'**라는 진실을 추적하는 미스터리 게임. 단, 세상에는 기억을 **갉아먹는 존재**들이 있어, 기억 게이지를 모두 잃으면 처음부터 다시 시작해야 한다.

---

## 1. 컨셉 정리 (사용자가 상상한 핵심 그대로 + 살 붙이기)

사용자가 구상한 핵심 요소를 정리하면 다음과 같고, 각 항목에 기획적 살을 붙였습니다.

| 사용자가 말한 것 | 기획으로 구체화 |
|---|---|
| 자신을 잊어버린 캐릭터 | 주인공은 기억상실 고양이. **얼굴이 처음엔 '?' 물음표**로 표시 |
| 물건을 찾으며 정체를 알아냄 | 물건 = **기억 조각(Memory Shard)**. 줍는 순간 회상 컷신 재생 |
| 왜 기억을 잃었는지도 찾음 | 메인 미스터리. 5개 챕터를 거치며 **반전**으로 밝혀짐 |
| 키보드 + 터치패드로 이동 | 두 가지 조작 모두 지원 (4-2절 참고) |
| 처음엔 얼굴이 물음표, 점점 알게 됨 | **정체성 게이지**가 차며 얼굴·이름·실루엣이 또렷해짐 |
| 집안 + 바깥 공원 같은 곳 | 5개 구역: 방 → 집 → 마당 → 공원 → (마지막 비밀 장소) |
| 기억을 더 잊게 하는 장애물 | **'망각(忘却) 존재'** = 적/장애물. 닿으면 기억 게이지 감소 |
| 기억 게이지 10칸, 다 쓰면 처음부터 | **메모리 미터 10칸** 시스템 (5절 참고) |
| 방에 컴퓨터·침대·게임기 | 튜토리얼 공간 '내 방'의 오브젝트들 |
| 숨겨진 물건 찾으면 다음 공간으로 이동 | **챕터 클리어 조건** = 핵심 기억 조각 N개 수집 |

## 2. 참고한 기존 게임 방식 (리서치)

이 컨셉에 잘 맞는 검증된 게임 방식들을 찾아 결합했습니다.

### 2-1. 기억상실 + 물건으로 기억 복원
- **Amnesia: The Dark Descent** — 주인공이 일기·메모·아이템을 모으며 자신이 처한 상황의 진실을 점진적으로 밝힘. "탐험을 통해 치유되는 기억상실"이라 탐험 자체가 보상이 되는 구조. → 우리 게임의 **물건=기억 조각** 핵심 루프의 근거.
- **Amnesia: Rebirth** — 기억을 되짚어가며 진실을 마주하고, **정신력(sanity)·괴물 회피** 요소 존재. → 우리의 **메모리 미터·망각 존재** 시스템과 직결.

### 2-2. 히든 오브젝트 / 기억 조각
- **히든 오브젝트 게임(HOG)** 장르 — 화면 속 숨은 물건을 찾는 방식. 최근에는 단순 찾기를 넘어 **서사·탐험·퍼즐이 결합된 어드벤처(AHOG)**로 진화. "꿈/기억의 조각을 맞춘다"는 프레이밍이 동기 부여에 효과적.
- **FRAGMENTS(Steam)** — 기억의 조각을 되찾는 '기억술사'가 주인공인 **탑다운 어드벤처**. → 탑다운 시점 + 조각 수집의 직접적 레퍼런스.

### 2-3. 고양이 주인공 / 분위기
- **Stray** — 고양이가 주인공인 탐험 어드벤처. 동물 시점의 조작·세계 탐험의 매력. → 주인공 무드의 레퍼런스.
- **Gris / Unpacking / A Memoir Blue** — 대사를 최소화하고 **시각적 연출과 사물로 이야기**를 전하는 감성 서사. → 컷신·연출 톤.

### 2-4. 미스터리·서스펜스 (선택하신 톤)
- **Return of the Obra Dinn** — 단서를 모아 '무슨 일이 있었는가'를 플레이어가 추리. → **'왜 기억을 잃었는가'** 추리 구조.
- **Eternal Darkness: Sanity's Requiem** — 정신력 게이지가 낮아지면 환각·왜곡 연출. → 메모리 미터가 낮을 때의 **공포·왜곡 연출** 아이디어.

> **결합 결과:** "고양이 시점의 잔잔한 탑다운 탐험"(Stray·Gris) + "물건으로 기억을 복원하는 루프"(Amnesia·FRAGMENTS) + "단서로 진실을 추리하는 미스터리"(Obra Dinn) + "기억을 갉아먹는 위협과 정신력 게이지"(Rebirth·Eternal Darkness).

## 3. 스토리 & 세계관 (미스터리·서스펜스 톤)

### 3-1. 도입
주인공 고양이는 **불 꺼진 방**에서 눈을 뜬다. 자신이 누구인지, 여기가 어디인지 모른다. 화면 속 자기 얼굴은 **물음표(?)**. 방 안의 물건들이 어렴풋이 익숙하지만 이름이 떠오르지 않는다. 그때 벽의 그림자 속에서 무언가가 스윽 — **기억을 먹는 존재**가 이미 집 안을 돌아다니고 있다.

### 3-2. 중심 미스터리 (왜 기억을 잃었나)
플레이어가 조각을 모으며 점진적으로 드러나는 진실. **3단 반전 구조**로 설계:

1. **표층(챕터 1~2):** "사고로 기억을 잃은 평범한 집고양이"인 줄 안다.
2. **중층(챕터 3~4):** 사실 이 고양이는 **누군가(주인 '하루')의 기억과 깊이 연결된 특별한 존재**였음이 드러난다. 청록색 무늬가 빛나는 건 이유가 있다.
3. **심층(챕터 5, 최종 반전):** 기억을 잃은 건 사고가 아니라 **스스로 지운 것** — 너무 아픈 이별(주인의 부재)을 견디지 못해 자신을 '망각 존재'로 만들고 있었다. '망각 존재'들은 외부의 적이 아니라 **고양이 자신의 일부**다. 마지막 선택: 기억을 **모두 받아들일지(진실 엔딩)**, 다시 잊을지(루프 엔딩).

> 미스터리·서스펜스 톤 포인트: 적이 사실 '나'였다는 반전, 안전하다고 믿은 집이 가장 위험한 곳이라는 역설, 게이지가 낮을 때 화면이 왜곡되는 불안한 연출.

### 3-3. 주인공 (캐릭터 설정)
- **외형:** 검은 몸 + 청록(시안)빛 귀 안쪽·발·꼬리 끝, 형광 연두색 큰 눈. 떠다니는 **발바닥(肉球) 문양**이 시그니처. 가슴엔 발자국 마크.
- **이름:** 게임 내내 'unknown / ???'. **마지막에 되찾는 마지막 기억 조각이 곧 자신의 이름**이다 (예: "녹턴(Nocturne)"). → 이름 자체가 최종 보상.
- **정체성 표현:** 얼굴이 ? → 흐릿한 윤곽 → 또렷한 표정 순으로 변화 (UI 6-2절).

## 4. 게임플레이 — 어떻게 하는 게임인가

### 4-1. 핵심 루프 (Core Loop)
```
구역 탐험 → 숨은 물건(기억 조각) 발견 → 회상 컷신 재생(정체성 ↑) 
   → 단서로 다음 장소의 잠금 해제 → 망각 존재 회피 → 다음 구역 이동 → 반복
                          �‾‾‾‾‾‾‾‾‾‾‾ (기억 게이지 관리) ‾‾‾‾‾‾‾‾‾‾‾↗
```
1. 탑다운 시점으로 구역을 자유 탐험한다.
2. 가구·구석·서랍 등을 조사해 **숨겨진 물건**을 찾는다.
3. 핵심 물건을 줍는 순간 **짧은 회상 컷신**이 재생되고 정체성이 또렷해진다.
4. 일부 기억은 **자물쇠 단서**(예: "서랍 비밀번호는 내 생일") → 다른 방의 잠금 해제로 연결 (가벼운 퍼즐).
5. 그 사이 **망각 존재**가 배회한다. 닿으면 메모리 미터 감소.
6. 구역의 핵심 조각을 다 모으면 다음 구역으로 통하는 문이 열린다.

### 4-2. 조작 (키보드 + 터치 둘 다 지원)
| 동작 | 키보드 | 터치패드 / 터치스크린 |
|---|---|---|
| 이동 | WASD / 방향키 | **화면의 가고 싶은 지점을 탭** → 그쪽으로 이동 (포인트-앤-클릭) |
| 조사·줍기 | E / Space (근처 물건 하이라이트 시) | 물건 직접 탭 |
| 살금살금(은신) | Shift 누르고 이동 | 화면 하단 '🐾' 버튼 홀드 |
| 기억 일지 열기 | Tab / I | 우상단 일지 아이콘 탭 |
| 일시정지 | Esc | 메뉴 버튼 |

> 접근성: 두 입력은 항상 동시 활성. 노트북 터치패드로 화면을 '문지르듯' 탭해도, 키보드로만 해도 끝까지 플레이 가능. 색약 모드, 텍스트 크기 옵션, 적 속도 조절 옵션 제공.

### 4-3. 숨은 물건 찾기 (히든 오브젝트)
- 각 구역에는 **핵심 기억 조각(필수)** 3~5개 + **선택 수집품(이스터에그)** 다수.
- 가까이 가면 물건이 **미세하게 반짝(시안색 글로우)** → 고양이의 청록빛과 톤 일치.
- 막혔을 때 **'직감' 힌트**: 메모리 미터 1칸을 소모하면 가장 가까운 미발견 핵심 물건 방향을 잠깐 표시 (리스크-보상).

### 4-4. 망각 존재 (장애물 / 적)
컨셉의 "기억을 더 잊게 하는 것"을 적으로 구체화. 미스터리 톤에 맞춰 **직접 싸우지 않고 회피·은신** 중심.

| 적 | 행동 | 대응 |
|---|---|---|
| **그림자 안개(Murk)** | 천천히 떠다님. 닿으면 미터 -1 | 우회, 빛 웅덩이에 숨기 |
| **속삭이는 잔상(Echo)** | 소리에 반응해 추격 | 살금살금(은신)으로 통과 |
| **공백(The Blank)** (보스급) | 챕터 끝 등장, 핵심 기억을 빼앗으려 함 | 모은 기억의 '빛'으로 밀어냄 (퍼즐형 대치) |

> 게이지가 낮을수록 적이 많아지고 화면이 흑백·왜곡되는 **서스펜스 강화 연출** (Eternal Darkness 오마주).

## 5. 핵심 시스템 — 메모리 미터 (기억 게이지 10칸)

사용자의 "쉽게 티가 열 칸, 다 쓰면 처음부터" 아이디어를 핵심 긴장 장치로 설계.

- **10칸**의 발바닥(🐾) 아이콘 게이지. 시작 시 일부만 채워진 상태(예: 4칸).
- **감소:** 망각 존재 접촉(-1), 힌트 사용(-1), 위험 지역 체류.
- **증가/회복:** 기억 조각 수집 시 +, '추억의 안전지대'(침대·따뜻한 햇살 자리)에서 휴식 시 서서히 회복.
- **0칸 = 완전 망각:** 모든 진행이 리셋되어 **그 회차 처음부터** 다시 시작.
  - 단, **하드 리셋 완화 옵션** 권장: 영구히 풀린 '확정 기억(코어 기억)'은 일지에 남아, 재시작 시 해당 컷신은 스킵 가능. → 좌절감을 줄이고 미스터리 학습 보상은 유지.
- **내러티브 통합:** 0칸 도달 = "다시 자신을 잊는" 것. 이 리셋 자체가 3-2절의 **루프 엔딩 복선**이 되도록 연출.

## 6. 구역(맵) 설계 — 방 → 집 → 바깥

총 5개 구역. 뒤로 갈수록 넓고 적이 많아짐.

### 6-1. 구역 목록
1. **챕터 1 · 내 방 (튜토리얼)** — 컴퓨터, 책상, **침대**, 게임기, 옷장.
   - 숨은 물건 예: 게임기 밑 *목걸이 이름표*, 컴퓨터 옆 *사진*, 침대 밑 *낡은 장난감 쥐*, 서랍 속 *일기장 한 페이지*.
   - 학습 목표: 이동·조사·줍기·메모리 미터·첫 회상.
2. **챕터 2 · 집 안** — 거실·주방·복도. 첫 망각 존재(Murk) 등장. 자물쇠 퍼즐 도입(사진 단서로 금고 열기).
3. **챕터 3 · 마당 / 현관** — 실내→야외 전환. 비 오는 밤 분위기, 은신 본격화(Echo 등장).
4. **챕터 4 · 공원** — 가장 넓은 탐험 구역. 분수·벤치·놀이터. 중층 반전이 밝혀지는 핵심 기억들.
5. **챕터 5 · ??? (비밀 장소)** — 기억의 근원. 최종 반전, 보스 'The Blank', 엔딩 선택.

### 6-2. 정체성 진행 표현 (얼굴 물음표 → 또렷해짐)
- HUD 좌상단 주인공 초상이 진행에 따라 변화:
  `? (물음표)` → `흐릿한 실루엣` → `눈만 또렷` → `표정 있는 얼굴` → `이름 표기 등장`.
- 챕터마다 새 단어가 채워지는 **정체성 카드**: 종(種) → 이름 → 사는 곳 → 주인 → "왜 잊었는가".

## 7. 기억 일지 (Memory Journal) — 미스터리 추리 도구

- 수집한 기억 조각이 **타임라인/관계도**로 정리됨.
- 일부 조각은 빈칸(`?`)으로 남아 **"무엇이 빠졌는가"**를 플레이어가 의식하게 함 (Obra Dinn식 추리감).
- 단서 조합 시 새로운 추론이 잠금 해제 → 다음 구역 진입 키가 되기도 함.

## 8. 아트 & 사운드 디렉션

- **비주얼:** 캐릭터의 **검정 + 시안 글로우 + 형광 연두** 팔레트를 게임 전체 톤으로 확장. 어두운 배경에 네온 포인트 → 미스터리·서스펜스에 적합. 기억 조각은 시안색으로 빛남.
- **연출:** 회상 컷신은 채도를 올린 따뜻한 색(과거) ↔ 현재는 차갑고 어두운 톤으로 대비.
- **게이지 저하 시:** 화면 가장자리 흑백 비네팅, 미세한 떨림·노이즈, 소리 왜곡.
- **사운드:** 잔잔한 피아노·앰비언트 기반. 적이 가까우면 저음 드론과 심장박동. 기억 회복 시 맑은 차임.

---

## 9. 난이도 & 접근성

- **스토리 모드:** 적 느림, 게이지 회복 빠름, 리셋 없음(0칸이어도 안전지대로 이동만).
- **표준 모드:** 위 시스템 그대로.
- **서스펜스 모드:** 적 다수, 회복 느림, 하드 리셋.
- 색약/텍스트 크기/한 손 조작/적 속도 슬라이더 등 옵션 제공.

## 10. 개발 로드맵 (제안)

| 단계 | 내용 | 산출물 |
|---|---|---|
| **P0. 프로토타입** | '내 방' 한 구역 + 이동(키보드·터치) + 줍기 + 메모리 미터 + 회상 1개 | 플레이 가능한 수직 슬라이스 |
| **P1. 코어 루프 완성** | 적 1종, 일지, 자물쇠 퍼즐, 정체성 UI | 챕터 1~2 |
| **P2. 콘텐츠 확장** | 챕터 3~5, 적 3종, 보스, 엔딩 분기 | 풀 캠페인 |
| **P3. 폴리시** | 사운드·연출·접근성·밸런싱 | 출시 빌드 |

> 기술 추천: 가볍게는 **웹(HTML5 Canvas/Phaser)** 또는 **Godot/Unity**. 터치+키보드 동시 지원이 쉬운 엔진을 권장. (원하시면 다음 단계로 웹 기반 플레이 가능한 프로토타입을 만들어 드릴 수 있습니다.)

## 11. 한눈에 보는 요약

- **무엇:** 기억 잃은 네온 고양이가 물건을 찾아 정체와 진실을 추적하는 미스터리 탐험 게임.
- **어떻게:** 탑다운으로 방→집→공원을 돌며 숨은 기억 조각 수집 (키보드 또는 터치).
- **긴장:** 기억을 갉아먹는 '망각 존재' + 10칸 메모리 미터(0이면 리셋).
- **성장:** 얼굴 물음표 → 또렷해지며 이름·정체가 밝혀짐.
- **반전:** 적은 사실 자기 자신, 기억상실은 스스로 택한 것 — 받아들일지 다시 잊을지 선택.
