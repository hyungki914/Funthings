## 0. 비전 & 포지셔닝

> **"눈을 떴을 때, 나는 내가 누구인지 몰랐다. 흩어진 물건 하나하나가 나를 다시 만들어 간다 — 나를 모두 잊기 전에."**

기억을 잃은 검은 고양이가 방 → 집 → 공원을 돌아다니며 **숨겨진 물건(기억 조각)을 찾아** 자신의 정체와 **'왜 기억을 잃었는가'**라는 진실을 추적하는 미스터리 게임. 세상에는 기억을 **갉아먹는 존재**들이 배회하고, 기억이 모두 흩어지면 마지막으로 떠올린 기억 하나가 다시 어둠 속으로 봉인된다.

**포지셔닝 한 줄:** *"GRIS의 무대사 감성 + Obra Dinn의 진실 추리 + Stray의 고양이 매력을, 1.5~3시간 탑다운 미스터리로 압축한 게임."*

### 디자인 기둥 (Design Pillars)
모든 설계 결정은 이 세 기둥에 복무한다. 기둥과 충돌하면 그 기능은 잘라낸다.

1. **사물이 곧 기억이다 (Objects are memory).** 모든 진실은 말이 아니라 *물건·공간·색의 변화*로 드러난다. 설명충 독백·NPC 금지.
2. **기억은 능동적으로 다룬다 (Memory is a verb).** 기억은 보는 것이 아니라 *비추고·따라가고·되찾는* 것. 플레이어의 손이 기억을 가지고 논다.
3. **잊는 것은 위협이자 자비다 (Forgetting is both threat and mercy).** 망각은 게임의 긴장 장치인 동시에 테마의 핵심 — 옳고 그름이 아니라 *사랑의 다른 얼굴*.

## 1. 컨셉의 출발점 (사용자 구상 → 기획)

사용자가 처음 구상한 핵심과, 그것을 v2.0에서 어떻게 구체화했는지.

| 사용자가 말한 것 | v2.0 기획 |
|---|---|
| 자신을 잊어버린 캐릭터 | 기억상실 고양이. 인게임은 **3/4 쿼터뷰**, 초상 UI는 **'?' 물음표**에서 출발 (D4) |
| 물건을 찾으며 정체를 알아냄 | 물건 = **기억 조각(Memory Shard)**. **글로우 OFF·3단 발견**(환경단서→상호작용→회상) (D2) |
| 왜 기억을 잃었는지도 찾음 | 메인 미스터리. **3개 챕터에 3단 반전**을 telegraph로 분산 (D3·D8) |
| 키보드 + 터치로 이동 | **v1.0: 키보드+게임패드+마우스 포인트앤클릭.** 순수 터치는 포스트런치 (D3) |
| 처음엔 물음표, 점점 알게 됨 | **정체성 카드**가 차며 초상이 또렷해짐 (단일 GameState로 HUD와 동기, D9) |
| 집안 + 바깥 공원 | **3개 구역: 방 → 집(+마당) → 공원(+비밀장소 압축)** (D3) |
| 기억을 더 잊게 하는 장애물 | **'망각 존재'** = 적. 닿으면 메모리 미터 감소 |
| 기억 게이지 10칸, 다 쓰면 처음부터 | **메모리 미터 10칸 + 빛 자원**의 2게이지. 0칸은 *처음부터*가 아니라 **후퇴(Setback)** (D1, 5절) |
| 방에 컴퓨터·침대·게임기 | 튜토리얼 공간 '내 방'의 오브젝트들 |
| 숨겨진 물건 찾으면 다음 공간 | **챕터 클리어 = 핵심 조각 N개 수집 → 문 개방** |

## 2. 참고한 기존 게임 방식 (리서치)

### 2-1. 기억상실 + 물건으로 기억 복원
- **Amnesia: The Dark Descent** — 일기·메모·아이템으로 진실을 점진 복원. "탐험을 통해 치유되는 기억상실". → **물건=기억 조각** 루프의 근거.
- **Amnesia: Rebirth** — 기억을 되짚으며 **정신력·괴물 회피**. → **메모리 미터·망각 존재**의 직계.

### 2-2. 단서 추리 / 기억 조각
- **히든 오브젝트(HOG) → 어드벤처(AHOG)** — 단순 찾기를 넘어 서사·탐험·퍼즐 결합. 단, 본작은 글로우 의존을 버리고 **환경형 3단 발견 + 추리**로 격상(D2).
- **FRAGMENTS(Steam)** — 기억 조각을 되찾는 탑다운 어드벤처. **가장 직접적 유사 콘셉트**(차별화 필요, 05 경쟁분석).

### 2-3. 고양이 주인공 / 감성 서사
- **Stray** — 고양이 주인공·탐험. **3/4 쿼터뷰** 시점·다이제틱 표현의 레퍼런스(D4).
- **Gris / Unpacking / A Memoir Blue** — 대사 최소화, **사물·색으로 이야기**. → 컷신·연출 톤(단, A Memoir Blue는 "너무 짧으면 시장 반응 미미"의 경고 사례, 05).

### 2-4. 미스터리·서스펜스
- **Return of the Obra Dinn** — 단서로 진실 추리. → **'왜 잊었나'** 추리 + **거짓 조각** 구조.
- **Eternal Darkness** — 정신력 저하 시 환각·왜곡. → 저(低)기억 연출(단, **광과민성 가드** 필수, D9).

> **결합:** 고양이 시점 탑다운 탐험(Stray·Gris) + 물건으로 기억 복원(Amnesia·FRAGMENTS) + 단서 추리(Obra Dinn) + 망각 위협·정신력(Rebirth·Eternal Darkness).

## 3. 스토리 & 세계관 (미스터리·서스펜스)

### 3-1. 도입
고양이는 **불 꺼진 방**에서 눈을 뜬다. 자신이 누구인지 모른다. 초상 UI는 **물음표(?)**. 물건들이 어렴풋이 익숙하지만 이름이 떠오르지 않는다. 벽 그림자 속에서 무언가가 스윽 — **기억을 먹는 존재**가 이미 집을 돌아다닌다.

### 3-2. 중심 미스터리 — 3단 반전 (3개 챕터에 분산, D8)
1. **표층(챕터1 · 방):** "사고로 기억을 잃은 평범한 집고양이"인 줄 안다.
2. **중층(챕터2 · 집+마당):** 청록 무늬는 **하루(주인)를 떠올릴 때만 빛난다** — 마법적 특별함이 아니라 **하루가 남긴 것**. ("선택받은 존재" 클리셰를 *관계의 특별함*으로 재정의, D8.)
3. **심층(챕터3 · 공원+근원):** 기억을 잃은 건 사고가 아니라 **스스로 지운 것** — 하루의 상실을 견디지 못해. '망각 존재'는 외부의 적이 아니라 **고양이 자신의 일부**. 단, 이 반전은 *선언*이 아니라 **챕터에 걸쳐 누적된 복선의 수긍**으로 온다(안 덤비는 Murk / 늦게 따라오는 물그림자 / 거짓 기억을 만드는 내 발). 마지막 선택: **받아들이기(진엔딩) vs 다시 잊기(루프 엔딩)** — 둘 다 *사랑의 다른 얼굴*, 어느 쪽도 처벌 아님(D8).

> 서스펜스 포인트: 적이 사실 '나', 안전하다 믿은 집이 가장 위험, 저기억 시 왜곡 연출. **신파 방지** — 슬픔은 독백이 결론을 말하지 않고 사물·행동·색으로 보여준다(독백 예산제, D8).

### 3-3. 주인공
- **외형:** 검은 몸 + 청록(시안) 귀안쪽·발·꼬리끝, 형광 연두 눈. 시그니처 **발바닥(肉球) 문양** + 가슴 발자국 마크.
- **인게임 표현(D4):** **3/4 쿼터뷰** 스프라이트. 눈이 안 보이는 각도는 **다이제틱 시그니처**로 — 이동 시 바닥 **시안 발자국 트레일**(제목과 직결), 머리 위 떠다니는 발바닥, 시안 림라이트. 정면 치비는 **초상/메뉴/회상 전용**.
- **이름:** 게임 내내 '???'. **최종 기억 조각이 곧 이름**("지로 / Ziro") = 최종 보상.
- **입모양:** 시그니처 `:3` 고양이 입(3자 모양 ω) — 도트 스프라이트에 반영.

## 4. 게임플레이 — 어떻게 하는 게임인가

### 4-1. 핵심 루프 (Core Loop) — v2.0
```
구역 탐험 → [환경 단서 포착] → 기억 비추기 / 발자국 추적으로 숨은 조각 좁히기
   → 상호작용으로 접근 → 회상(정체성↑) → 단서로 잠금 해제 → 망각 존재 회피
        ↖___________________ 메모리 미터(생명) · 빛 자원(재화) 관리 ___________________↙
```
1. 탑다운으로 구역을 탐험한다. **글로우는 기본 OFF.**
2. **환경 단서**(흩어진 사료·긁힌 자국 등)로 "이 근처에 뭔가 있다"를 읽는다.
3. **기억 비추기(Project)** 또는 **발자국 추적(Trail)** 동사로 숨은 조각/통로를 드러낸다 → "어떤 렌즈를 들까"의 의사결정.
4. **상호작용**(서랍 열기·가구 밀기·올라가기)으로 접근 → **회상 컷신** 재생, 정체성 또렷.
5. 일부 기억은 **자물쇠 단서** → 다른 곳의 잠금 해제(데이터 주도 퍼즐).
6. 그 사이 **망각 존재** 회피. 핵심 조각을 다 모으면 다음 구역 문 개방.

> **코어 동사(D2):** ①이동 ②상호작용/줍기 ③**기억 비추기** ④**발자국 추적** (+물리 상호작용 검토). 챕터마다 동사 1개씩 해금해 *능력 성장*을 체감시킨다(정체성 카드에 패시브 부여).

### 4-2. 조작 (v1.0 = PC, D3/C3)
| 동작 | 키보드 | 게임패드 | 마우스 |
|---|---|---|---|
| 이동 | WASD / 방향키 | 좌스틱 | **가고 싶은 지점 클릭** → 경로 이동(그리드 A*) |
| 조사·줍기 | E / Space | A / ✕ | 물건 클릭 |
| 기억 비추기 | Q (장착 렌즈 순환) | LB | 휠/우클릭 |
| 발자국 추적 | L 홀드 | LT 홀드 | 좌하단 버튼 홀드 |
| 살금살금(은신) | Shift 홀드 | RB 홀드 | — |
| 기억 일지 | Tab / I | Y | 우상단 아이콘 |
| 일시정지 | Esc | Start | 메뉴 버튼 |

> 입력은 **Intent 추상화 레이어**로 통합되어 동시 활성·충돌(키 이동 중 클릭 이동 등)을 규칙으로 처리(04 §8). 순수 터치스크린 UX는 포스트런치 모바일 포트. 접근성: 한손/원클릭은 마우스로 상당부분 충족, 색약·텍스트크기·적속도·플래시감소 옵션 제공(9절).

### 4-3. 숨은 물건 찾기 — 환경형 3단 발견 (D2)
- 각 구역: **핵심 기억 조각(필수) 3~5개** + **에코 조각(선택)** + 후반 **거짓 조각(Trap)**.
- **글로우 OFF 기본.** 발견은 ① 환경 단서 → ② 기억 비추기/추적/상호작용 → ③ 회상의 3단계.
- **거짓 조각 추리:** 거짓은 "행복한 가짜 기억"이지만 *진실의 파편*(시든 꽃·멈춘 달력)이 새어나옴. 일지 단서와 교차검증해 판별(D8).
- 막혔을 때 **'직감' 힌트**: **빛 자원** 1 소모(메모리 미터와 분리 — D1). 가장 가까운 미발견 조각 방향 표시.

### 4-4. 망각 존재 (적) — 회피·은신 중심
| 적(v1.0) | 감지 | 대응 | 식별(색 아님, D9) |
|---|---|---|---|
| **그림자 안개(Murk)** | 시각(시야 3단 게이트: 거리·각도·차단) | 우회, 빛 웅덩이/엄폐 뒤로 | **뭉게지는 실루엣** |
| **속삭이는 잔상(Echo)** | 청각(소음 반경, 정지=무소음) | 은신·정지·소리 미끼 유인 | **흩날리는 모션** |
| **공백(The Blank)** (보스, v1.0 = 1페이즈) | 최종장 | 모은 기억의 **빛으로 비춰** 약화(퍼즐형) | 거대한 자아 그림자 |

> 저기억 시 적이 늘고 화면이 흑백·왜곡(서스펜스 연출). 단 이 연출은 **'기억 안정도' 별도값**에 연동해 *감상 가능*하게 하고, **광과민성 가드**(플리커<3Hz·흔들림/색수차 토글) 적용(D9).

## 5. 핵심 시스템 — 2게이지 + 후퇴(Setback) (D1) ⭐개정

> v1의 "단일 미터(생명=재화), 0칸=처음부터"는 ① 힌트가 죽은 시스템이 되고 ② 하드 리셋이 *긴장이 아니라 분노*가 되는 결함으로 판명되어 **2게이지 + 후퇴**로 재설계. (상세 수치 03 §1, 세이브 04 §7.)

### 5-1. 메모리 미터 (생명 / 페이싱) — 발바닥 10칸
- **감소:** 망각 존재 접촉, 거짓 조각 획득, 위험지역 자연감소. *(힌트로는 깎이지 않음.)*
- **회복:** 코어 조각 수집(+1칸), 안전지대 휴식.
- **0칸 = 후퇴(Setback):** *처음부터*가 아니라 **마지막 안전지대 체크포인트로 귀환** + 가장 최근 코어 회상 1개 **임시 봉인**(같은 자리에서 재획득 가능, 위치 표시) + 30초 최대 왜곡 연출. **코어 기억은 영구 보존(다시 잃지 않음).**
- **표현(D9):** 칸 토큰 `empty/half/full/danger` 4상태(0.5칸=반쪽 발바닥), 5+5 그룹핑, 위험 시 **형태 변화**(금/흩어짐)로 색약자도 인지.

### 5-2. 빛 자원 (Light / 재화) — 신설
- 코어/에코 조각으로 충전되는 **별도 소모 자원.**
- 용도: 직감 힌트, 거짓 판별, 비상 빛 웅덩이, **기억 비추기**.
- → "도움받기(재화)"가 "죽음(생명)"과 분리되어, 힌트 시스템이 실제로 살아난다.

### 5-3. 내러티브 통합 & 모드별 동작
- 후퇴할 때마다 오프닝 독백("…어둡다")을 짧게 깔아 **루프 엔딩 복선**을 *더 자주* 체험(시스템적 좌절 없이 테마만 취함).
- **스토리 모드:** 후퇴 없음(가장 가까운 안전지대로 이동만). **표준 모드:** 후퇴. **서스펜스 모드(포스트런치, 옵트인):** 원하는 이에게만 하드 리셋 제공.

## 6. 구역(맵) 설계 — 방 → 집 → 공원 (v1.0 = 3챕터, D3)

### 6-1. 구역 목록
1. **챕터1 · 내 방 (튜토리얼/표층반전)** — 컴퓨터·침대·게임기·옷장. 학습: 이동·상호작용·**3단 발견**·메모리 미터·첫 회상. (적 없음/도입 1체.)
2. **챕터2 · 집 + 마당 (중층반전)** — 거실·주방·복도→비 오는 마당. **Murk(시각)·Echo(청각)** 등장, 자물쇠 퍼즐, 빛=하루의 기억 단서. *(구 '마당' 흡수.)*
3. **챕터3 · 공원 + 근원 (중층절정+심층반전)** — 가장 넓은 탐험 + 거짓 조각 추리 + 보스 'The Blank'(1페이즈) + 엔딩 선택. *(구 '비밀장소' 압축.)*

> 컷한 분량(독립 챕터4·5, 보스 3페이즈)은 **포스트런치 무료 업데이트**로 복원(05 로드맵).

### 6-2. 정체성 진행 표현 (단일 GameState로 동기, D9)
- 초상 진화: `? → 흐릿한 실루엣 → 눈만 또렷 → 표정 → 이름`. **HUD와 정체성 카드가 같은 값을 표시**(과거 1/5 vs 3/5 불일치 수정).
- 정체성 카드 슬롯: 종(種) → 사는 곳 → 주인 → 이름 → "왜 잊었는가". **각 슬롯에 패시브 효과**(예: [종]→발자국 추적, [집]→안전지대 회복+, [이름]→빛 자원 최대치+) (D2).

---

## 7. 기억 일지 / 추리 보드 (미스터리의 본체, D9)

- 수집 조각이 **타임라인 + 관계도**로 정리. *전용 화면 신설*(과거엔 HUD 아이콘만 있었음).
- 일부 조각은 빈칸(`?`)으로 남아 "무엇이 빠졌나"를 의식하게 함(Obra Dinn식).
- 단서 조합 시 새 추론 잠금 해제 → 다음 구역 진입 키가 되기도. **세션 종료 시 "다음에 풀 미스터리 훅"을 명시**해 복귀 동기 부여(리텐션).

---

## 8. 아트 & 사운드 디렉션

> **인게임 비주얼 = 일본식 픽셀아트(ドット絵) + HD-2D 네온 블룸.** 상세·실제 에셋은 **[09 아트 디렉션](./09_art_direction_pixel.md)** 및 [`art/`](./art/) 참고. (SVG 목업은 UI 스펙용, 픽셀아트가 인게임 정본 — `art/png/comparison.png`의 BEFORE/AFTER.)
> 계보: Chrono Trigger·Sea of Stars(탑다운 JRPG 타일+스프라이트) + Octopath HD-2D(블룸/조명) + Tails Noir(네온 느와르). 16px 타일 · 32px 캐릭터.

- **시점(D4):** 인게임 **3/4 쿼터뷰** + 다이제틱 시그니처(발자국 트레일·떠다니는 발바닥·시안 림라이트). 정면 치비는 초상 전용.
- **비주얼:** **검정 + 시안 글로우 + 형광 연두** 팔레트. 단 **색 역할 고정**(시안=중립UI, 연두=긍정/해금) + **색+형태 이중 인코딩**으로 색약 대응(D9).
- **연출:** 회상은 따뜻한 색(과거) ↔ 차가운 현재 대비. 저기억 연출은 '기억 안정도' 값에 연동, **광과민성 가드** 필수.
- **사운드:** 잔잔한 피아노·앰비언트. 적 근접 시 저음 드론·심장박동. **Echo 청각 모델을 위해 '내 발소리 크기'를 청각 피드백**으로 전달(스텔스 공정성). 시각 연출을 줄인 만큼 긴장을 오디오가 보강.

## 9. 난이도 & 접근성 (1급 시민, D9)

- **모드(v1.0):** 스토리(적 느림·후퇴 없음) / 표준(후퇴). 서스펜스(하드리셋)=포스트런치.
- **접근성 P0:** 색약 모드(색+형태 이중) · 텍스트 크기 · 적 속도 슬라이더 · **화면 흔들림/플래시/색수차 끄기**(광과민성) · 퍼즐 스킵.
- **접근성 보강:** 거짓 조각 판별을 *색 외 채널*(아이콘 떨림·소리 질감)로도, 핵심 독백 음성/낭독 옵션 검토, **사별 주제 트리거 워닝 + 도움 안내**(민감 주제 배려).

## 10. 개발 로드맵 (요약 — 상세 05)

5단계 게이트형. 총 **13~18개월(2인 풀타임 가정)**. **M1 게이트에서 데모·위시리스트 데이터로 "계속/피벗/중단" 결정.**

| 마일스톤 | 핵심 | 통과 게이트 |
|---|---|---|
| **M0 프로토** | 이동+3단발견+2게이지+후퇴+동사1+Murk 1 | "코어 동사가 재미있나" + "후퇴가 긴장>분노인가" |
| **M1 버티컬 슬라이스** | 챕터1 완성 + 챕터2 도입, 톤 확정, 일지/정체성 UI | **데모로 낼 품질인가?** (위시리스트·완주율) |
| **M2 알파** | 챕터1~3 콘텐츠, 적2·보스1페이즈, 2엔딩 — 기능완성 | 처음~끝 플레이 가능? |
| **M3 베타** | 밸런싱·접근성·버그·로컬라이징(영/한) | 크래시0·완주율 목표 |
| **M4 출시** | 스토어·트레일러·런치 | 위시리스트 ≥1.5만(생존선)/목표 3만 |

- **엔진: Godot 4.x**(2D·A*·입력·세이브 내장, MIT 무료) + **한/영 폰트 스파이크 P0 최우선**(상세 04).
- **검증 게이트:** 글로우 OFF로 신규 테스터가 힌트 없이 챕터1 코어 4개를 3~6분 내(개당 45~90초, 좌절률<15%) 발견 + 후퇴 정서 "긴장>분노" ≥70%.

## 11. 한눈에 보는 요약 (v2.0)

- **무엇:** 기억 잃은 네온 고양이가 물건을 찾아 정체·진실을 추적하는 미스터리 탐험 게임(PC, $14.99 권고).
- **어떻게:** 3/4 쿼터뷰로 방→집→공원을 돌며, **기억 비추기·발자국 추적**으로 숨은 조각을 능동 발견(글로우 OFF·3단).
- **긴장:** 망각 존재 + **메모리 미터(생명) / 빛 자원(재화) 2게이지**. 0칸은 처음부터가 아니라 **후퇴**.
- **성장:** 챕터마다 동사 해금 + 정체성 카드(패시브) → 초상이 또렷해지며 이름·정체 복원.
- **반전:** 적은 사실 자기 자신(누적 복선), 기억상실은 스스로 택한 것 — 받아들이거나 다시 잊거나, 둘 다 사랑의 다른 얼굴.
