## ⚙ v2.0 개정 반영 (레벨 리뷰 → [00 결정 로그](./00_design_review.md) D7)

> 아래 ASCII 맵(§1~§5)은 v1 스케치다. "그림"이 아니라 *플레이 가능한 공간*이 되려면 아래 정량화가 필수. **충돌 시 본 블록 우선.**
>
> 1. **플레이어 속도 = 모든 설계의 기준 (D7).** 보행 **3.2** / 은신 **1.9** 타일/s. "Echo 추격 3.0 < 보행 3.2" 보장, **발각 시 빛 웅덩이까지 ≤4타일** 룰을 모든 Echo 구역에 적용.
> 2. **통로 폭 재설계.** 시야 반경(3.5)+2 = **최소 6타일** 폭 + 순찰선과 평행한 커버 라인(소파 등)으로 "커버 투 커버". 시야 3.5 vs 통로 3~5타일이면 우회로가 물리적으로 불가능했음. **모든 게이트에 우회로 ≥2** 보장.
> 3. **순찰 경로 = 데이터.** `M`은 스폰일 뿐. 각 적에 **웨이포인트 + 속도 + 위상(phase)** 표 작성. 검증 공식: **"안전 윈도우 ≥ 플레이어 통과시간 + 1.0s"**. (예: Murk A/B 같은 경로·위상 50% → 통로 앞 ~3.5s 윈도우 주기.)
> 4. **좌표 완전성 + 락-키 도달성.** 모든 코어/에코/거짓/**키** 좌표를 그리드에 빠짐없이 마킹(누락된 C2-4 등). `키 좌표 → 게이트 좌표` 도달성을 **BFS로 검증**(잠긴 영역에 마지막 코어가 갇히지 않게).
> 5. **글로우 OFF · 3단 발견 (D2).** 모든 코어 조각에 "①환경 단서 → ②기억 비추기/추적/상호작용 → ③회상" 의무화. → 챕터1은 코어가 한 화면에 몰려 있어 **맵을 1.5~2배 확장 또는 동선 비선형화**.
> 6. **보스룸(최종장) 정량화 + "이동 안전지대" (충돌 C4).** 보스룸 11×9 이상으로 확장, 코어 3개를 보스에서 **등거리 ≥3타일** 삼각 배치, **페이즈별 안전 코너 좌표 명시** + 그랩 회피 폭 보장. 안전지대 0 대신 *고양이가 비춘 빛이 만드는 일시 웅덩이*(후퇴 시스템과 정합).
> 7. **챕터4 추리-미터 충돌 해소 (G).** 거짓 조각은 **줍기 전 비파괴 관찰**(인접 시 색온도/그림자 단서 0칸 비용 노출), 첫 오답은 페널티 경감. 탐험 자체를 처벌하지 않게.
> 8. **분기 로직 수정 (충돌 C2).** §4 "거짓 0개 도달 → 진엔딩 가산점"은 **무효**(엔딩은 마지막 선택만으로 분기, D8). 거짓 조각은 *미터 압박 + 최종장 환각 강화* 기능만 유지.
> 9. **실측 표 + 02↔03 오버레이 검증.** 챕터별 **타일맵 크기·코어/적/안전지대 수·목표 시간**을 표로(합 1.5~3시간 산술 검증). 맵 위에 시야콘/청각원/순찰선을 *실측 스케일로 오버레이*하는 합동 검증 패스 필수.
>
> **챕터 재편(D3):** **5 → 3챕터.** 구 '마당'은 챕터2(집)에 흡수, 구 '비밀장소'는 챕터3(공원) 클라이맥스로 압축. 아래 §3~§5는 포스트런치 복원용 자료로 보존.


## 6. 공통 레벨 디자인 원칙
1. **코어 조각은 항상 동선 끝/깊은 곳**에 둬 탐험을 유도. 에코는 곁가지에 숨겨 호기심 보상.
2. **안전지대(☼)는 적 순찰로의 사정거리 밖**에 배치 — "쉼-위험-쉼" 리듬.
3. **난이도 곡선:** 적 0 → 2 → 3 → 다수 → 보스. 안전지대 수: 1 → 1 → 1 → 2 → 0.
4. **거짓 조각**은 챕터3에서 1개로 '학습', 4에서 3개로 '시험', 5에서 다수로 '클라이맥스'.
5. **되돌아가기(백트래킹)** 허용: 클리어한 구역은 안전지대로 재방문해 회복·에코 수집 가능(단, 적은 리스폰).
6. **읽히는 공간:** 빛(시안 글로우)은 항상 "상호작용/안전", 검은 안개는 "위험"으로 색 언어 일관 유지.
